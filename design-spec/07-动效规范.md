# 07 动效规范

## 1. 自定义关键帧（tailwind.config.js，全部原样可复用）

| 动画类 | keyframes | 参数 | 用途 |
|---|---|---|---|
| `animate-fade-in` | opacity 0→1 | 0.3s ease-out | 一般入场 |
| `animate-slide-up` | opacity 0→1 + translateY(10px)→0 | 0.3s ease-out | 卡片/区块入场 |
| `animate-slide-down` | opacity 0→1 + translateY(-10px)→0 | 0.3s ease-out | 顶部下拉面板 |
| `animate-slide-in-right` | opacity 0→1 + translateX(20px)→0 | 0.3s ease-out | Toast 入场 |
| `animate-scale-in` | opacity 0→1 + scale(0.95)→1 | **0.2s** ease-out | 下拉菜单/浮层 |
| `animate-pulse-slow` | Tailwind pulse | 3s cubic-bezier(0.4,0,0.6,1) | 呼吸提示 |
| `animate-shimmer` | background-position -200%→200% | 2s linear infinite | 微光扫过 |
| `animate-glow` | 光晕 20px/25% → 30px/40% | 2s ease-in-out alternate | 品牌发光按钮 |

## 2. 时长与缓动约定（全站只这几档）

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover/颜色/边框/开关等微交互 | **200ms** | ease-out（开关用 ease-in-out） |
| 浮层/菜单入场 | **200ms**（scale-in） | ease-out |
| 弹窗遮罩与内容进入 | **250ms** | ease-out |
| 弹窗退出 | **200ms** | ease-in |
| 卡片过渡、侧栏宽度、入场动画 | **300ms** | ease-out |
| 表格行 hover | 150ms | —（transition-colors） |
| 骨架屏 | Tailwind pulse 2s | — |
| 加载圈 | spin 0.75s | linear（LoadingSpinner）/ 默认 1s |

**永远 ease-out 入、ease-in 出**；没有弹跳/回弹类缓动。

## 3. 交互动效（微反馈）

| 交互 | 动效 |
|---|---|
| 按钮按下 | `active:scale-[0.98]`（全局按钮统一） |
| 卡片 hover | `-translate-y-0.5`（上浮 2px）+ 阴影升级 card→card-hover，300ms |
| 侧栏收缩 | 宽度 300ms；文字 `max-width→0 + opacity + translateX(-4px)` 120–220ms 分层过渡 |
| 下拉箭头 | `rotate-180` 200ms |
| 侧栏遮罩 | Vue `<transition name="fade">`（opacity） |
| Logo hover | `opacity-80` |
| 菜单点击后关抽屉 | 延时 150ms 再收起（让导航反馈先发生） |

## 4. 弹窗 Vue transition（BaseDialog 实装）

```css
.modal-enter-active { transition: opacity 250ms ease-out; }
.modal-leave-active { transition: opacity 200ms ease-in; }
.modal-enter-from, .modal-leave-to { opacity: 0; }
.modal-enter-active .modal-content { transition: transform 250ms ease-out, opacity 250ms ease-out; }
.modal-enter-from .modal-content, .modal-leave-to .modal-content {
  transform: scale(0.95); opacity: 0;
}
```

## 5. 无障碍降级（必须照抄）

```css
@media (prefers-reduced-motion: reduce) {
  /* 弹窗过渡全部降到 1ms，位移归零 */
  .modal-enter-active, .modal-leave-active, … { transition-duration: 1ms; transition-delay: 0ms; }
  .modal-enter-from .modal-content, .modal-leave-to .modal-content { transform: none; }
}
```

## 6. 页面切换

- 顶栏有 NavigationProgress 进度条组件（路由跳转时顶部进度反馈）。
- 路由本身无页面级 transition（内容直接切换，靠 `animate-slide-up` 等局部入场）。

> 做新页面建议：区块用 `animate-slide-up`，同栅格的卡片可加递增 `animation-delay`（50ms 步进）制造级联，但单页总入场不超过 600ms。
