常用弹窗宽度档：确认框 `max-w-md`（448px）/ 表单 `max-w-lg`（512px）/ 大表单 `max-w-2xl`（672px）/ 详情 `max-w-3xl`（768px）。

## 5. 一致性检查清单（新页面交付前过一遍）

- [ ] 每个颜色类都有 `dark:` 镜像
- [ ] 页面底 `bg-gray-50 dark:bg-dark-950`，卡片底 `bg-white dark:bg-dark-800(/50/70)`
- [ ] 主文字 `text-gray-900 dark:text-white`，辅助 `text-gray-500 dark:text-dark-400`
- [ ] 控件圆角 `rounded-xl`，容器 `rounded-2xl`，徽章/圆点 `rounded-full`
- [ ] 按钮用 `btn btn-{variant}` + 尺寸档，别手写按钮样式
- [ ] 输入框用 `.input`（焦点青环），标签用 `.input-label`
- [ ] 语义色走四件套公式，别发明新色值
- [ ] 图标 Heroicons outline、stroke 1.5（强调 2）、`currentColor`
- [ ] 区块间距 `space-y-6`/`gap-4`，卡内边距 `p-4~p-6`
- [ ] 动效只用 200/250/300ms + ease-out，按下 `scale-[0.98]`
- [ ] 弹窗有遮罩模糊 + `scale(0.95)` 入场 + ESC/点遮罩关闭
- [ ] 空态/加载态/错误态三态齐全（EmptyState / spinner / skeleton）
- [ ] 移动端：侧栏抽屉、统计卡 2 列、表格横向滚动、隐藏次要文字（`hidden sm:flex`）
