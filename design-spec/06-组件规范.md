# 06 组件规范

> 全部规格提取自 `src/style.css` 的 `@layer components` 与通用组件源码。每条给出「类名 → 规格 → HTML 用法」。
> 所有类在 light/dark 双模式下成对定义，HTML 示例中暗色已内含。

## 1. 按钮 Button

**基类 `.btn`**：
- 布局 `inline-flex items-center justify-center gap-2`
- 形状 `rounded-xl px-4 py-2.5 text-sm font-medium`
- 过渡 `transition-all duration-200 ease-out`
- 按下 `active:scale-[0.98]`；禁用 `opacity-50 cursor-not-allowed`
- 焦点 `focus:ring-2 focus:ring-primary-500/50 focus:ring-offset-2`

**变体**：

| 类 | 规格 |
|---|---|
| `.btn-primary` | 渐变底 `from-primary-500 to-primary-600`（水平渐变），白字，`shadow-md shadow-primary-500/25`；hover `from-primary-600 to-primary-700` + `shadow-lg shadow-primary-500/30` |
| `.btn-secondary` | 白底（暗 dark-800）`text-gray-700`，边框 `gray-200/dark-600`，`shadow-sm`；hover `bg-gray-50/dark-700` + 边框加深 |
| `.btn-ghost` | 全透明，`text-gray-600 dark:text-gray-300`；hover `bg-gray-100 dark:bg-dark-800` |
| `.btn-danger` | 渐变 `red-500→600`，白字，红染阴影（同 primary 公式） |
| `.btn-success` | 渐变 `emerald-500→600`，白字，绿染阴影 |
| `.btn-warning` | 渐变 `amber-500→600`，白字，琥珀染阴影 |

**尺寸**：

| 类 | 规格 |
|---|---|
| `.btn-sm` | `rounded-lg px-3 py-1.5 text-xs` |
| `.btn-md` | `rounded-xl px-4 py-2 text-sm` |
| `.btn-lg` | `rounded-2xl px-6 py-3 text-base` |
| `.btn-icon` | `rounded-xl p-2.5`（正方形图标按钮，配 `h-5 w-5` 图标） |

```html
<button class="btn btn-primary">保存</button>
<button class="btn btn-secondary">取消</button>
<button class="btn btn-danger btn-sm">删除</button>
<button class="btn btn-ghost btn-icon" aria-label="刷新">…svg…</button>
```

## 2. 输入框 Input

**`.input`**：
- `w-full rounded-xl px-4 py-2.5 text-sm`
- 白底（暗 dark-800），边框 `gray-200/dark-600`，文字 `gray-900/gray-100`
- placeholder `text-gray-400 dark:text-dark-400`
- 过渡 200ms；**焦点** `border-primary-500 + ring-2 ring-primary-500/30`（青色焦点环是全站识别点）
- 禁用 `bg-gray-100 dark:bg-dark-900 cursor-not-allowed`
- 报错追加 `.input-error`：`border-red-500` + 红 ring `/30`

配套：`.input-label`（`mb-1.5 block text-sm font-medium text-gray-700 dark:text-gray-300`）、`.input-hint`（`mt-1 text-xs text-gray-500 dark:text-dark-400`）、`.input-error-text`（`mt-1 text-xs text-red-500`）。

细节：数字输入框隐藏原生 spinner；暗色下 date/time 类输入补 `color-scheme: dark`。

```html
<div>
  <label class="input-label">名称</label>
  <input class="input" placeholder="请输入…" />
  <p class="input-hint">不超过 50 个字符</p>
</div>
```

## 3. 卡片 Card

| 类 | 规格 |
|---|---|
| `.card` | 白底（暗 `dark-800/50`）、`rounded-2xl`、边框 `gray-100/dark-700/50`、`shadow-card`、过渡 300ms |
| `.card-hover` | 追加：hover `-translate-y-0.5 + shadow-card-hover` + 边框加深 |
| `.card-glass` / `.glass-card` | 玻璃版：白 70%（暗 dark-800/70）+ `backdrop-blur-xl` + `border-white/20` + `shadow-glass` + `rounded-2xl` |
| `.card-header` | `px-6 py-4` + 底边框 |
| `.card-body` | `p-6` |
| `.card-footer` | `px-6 py-4` + 顶边框 |

```html
<div class="card card-hover">
  <div class="card-header"><h3 class="text-base font-semibold">标题</h3></div>
  <div class="card-body">…</div>
</div>
```

## 4. 统计卡 StatCard

- **仪表盘变体**：`card p-4` + `flex items-center gap-3`；图标底座 `rounded-lg bg-{hue}-100 p-2 dark:bg-{hue}-900/30`（图标 20px、stroke-2、`text-{hue}-600/400`）；标签 `text-xs font-medium text-gray-500 dark:text-dark-400`；数值 `text-xl font-bold`
- **标准 `.stat-card`**：`card p-5 flex items-start gap-4`；图标底座 `h-12 w-12 rounded-xl text-xl`；数值 `.stat-value` `text-2xl font-bold truncate`；标签 `.stat-label` `text-sm text-gray-500 dark:text-dark-400`；趋势 `.stat-trend` `mt-1 text-xs font-medium`（涨 emerald / 跌 red）

底座四色：primary / emerald(success) / amber(warning) / red(danger)，全部走 02 章「100 → 600 → dark:900/30 → dark:400」公式。

## 5. 表格 Table

**容器 `.table-container`**：`overflow-x-auto rounded-xl border gray-200/dark-700`（嵌入卡片时用 TablePageLayout 的 `rounded-2xl` 版本）。

| 元素 | 规格 |
|---|---|
| `.table` | `w-full text-sm` |
| `th` | `px-4 py-3 text-left font-medium text-gray-600 dark:text-dark-300`，底 `bg-gray-50 dark:bg-dark-800/50` + 底边框 |
| `td` | `px-4 py-3 text-gray-700 dark:text-gray-300`，行底边框 `gray-100/dark-800`（末行无线） |
| 行 hover | `bg-gray-50 dark:bg-dark-800/30`，过渡 150ms |
| 粘性表头（表格页版） | `px-5 py-4`，`bg-gray-50/80 dark:bg-dark-800/80 backdrop-blur-sm`，`sticky top-0 z-[1]` |

## 6. 徽章 Badge

`.badge` 基类：`inline-flex items-center gap-1 rounded-full px-2.5 py-0.5 text-xs font-medium`。

| 变体 | light | dark |
|---|---|---|
| `.badge-primary` | `bg-primary-100 text-primary-700` | `bg-primary-900/30 text-primary-400` |
| `.badge-success` | `bg-emerald-100 text-emerald-700` | `bg-emerald-900/30 text-emerald-400` |
| `.badge-warning` | `bg-amber-100 text-amber-700` | `bg-amber-900/30 text-amber-400` |
| `.badge-danger` | `bg-red-100 text-red-700` | `bg-red-900/30 text-red-400` |
| `.badge-gray` | `bg-gray-100 text-gray-700` | `bg-dark-700 text-dark-300` |
| `.badge-purple` | `bg-purple-100 text-purple-700` | `bg-purple-900/30 text-purple-400` |

状态点（StatusBadge）：徽章内放 `h-1.5 w-1.5 rounded-full bg-{hue}-500` 圆点 + 文字。

## 7. 下拉菜单 Dropdown

- `.dropdown`：`absolute z-50`，白底（暗 dark-800），`rounded-xl`，边框，`shadow-lg`，`py-1`，**入场 `animate-scale-in`（0.2s），transform-origin 右上**
- `.dropdown-item`：`px-4 py-2 text-sm text-gray-700 dark:text-gray-300 flex items-center gap-2`，hover `bg-gray-100 dark:bg-dark-700`
- 顶栏锚定写法：容器 `relative`，菜单 `absolute right-0 top-full mt-2 w-48`

## 8. 弹窗 Modal

| 部分 | 规格 |
|---|---|
| `.modal-overlay` | `fixed inset-0 z-50 bg-black/50 backdrop-blur-sm flex items-center justify-center p-2 sm:p-4` |
| `.modal-content` | `w-full max-h-[95vh] sm:max-h-[90vh]`，白底（暗 dark-800），`rounded-2xl shadow-2xl` + 边框，纵向 flex |
| `.modal-header` | `px-4 py-3 sm:px-6 sm:py-4` + 底边框，标题 `text-lg font-semibold`，右侧关闭钮 |
| `.modal-body` | `px-4 py-3 sm:px-6 sm:py-4 flex-1 overflow-y-auto` |
| `.modal-footer` | 同 header 内距 + 顶边框，`flex justify-end gap-3`（右对齐按钮组） |

**动效**（Vue transition）：遮罩 opacity 250ms ease-out 进入 / 200ms ease-in 退出；内容同时 `scale(0.95)→1`。`body.modal-open { overflow:hidden }` 锁滚动。尊重 `prefers-reduced-motion`（降到 1ms）。

**Dialog 变体**（确认框 BaseDialog/ConfirmDialog）：遮罩 `bg-black/40 dark:bg-black/60`，容器 `rounded-2xl max-h-[90vh] shadow-xl`，footer 特有浅底 `bg-gray-50/60 dark:bg-dark-900/40`。

## 11. 开关 Toggle

组件版（Toggle.vue）：轨道 `h-6 w-11 rounded-full border-2 border-transparent`，关 `bg-gray-200 dark:bg-dark-600`、开 `bg-primary-600`，过渡 200ms；滑块 `h-5 w-5 rounded-full bg-white shadow`，开时 `translate-x-5`；焦点 `ring-2 ring-primary-500`。

style.css 版 `.switch`：同尺寸，开态 `bg-primary-500`。

## 12. 进度条 Progress

```
.progress：h-2 rounded-full bg-gray-200 dark:bg-dark-700 overflow-hidden
.progress-bar：h-full rounded-full 渐变 from-primary-500 to-primary-400，宽度过渡 300ms
配额分档：正常 primary-500；≥75% amber-500；≥95% red-500（迷你版 h-1.5）
```

## 13. 空状态 EmptyState

```
.empty-state：flex flex-col items-center justify-center px-4 py-12 text-center
图标容器：mb-5 h-20 w-20 rounded-2xl bg-gray-100 dark:bg-dark-800（内置 inbox 图标 h-10 w-10 stroke-1.5 text-gray-300）
标题：.empty-state-title  text-lg font-medium（mb-1）
描述：.empty-state-description  text-sm text-gray-500 max-w-sm
操作区：mt-6，放 .btn .btn-primary（前置 plus 图标）
```

## 14. 加载态

**`.spinner`**：`h-5 w-5 rounded-full border-2 border-current border-t-transparent animate-spin`。

LoadingSpinner 组件尺寸档：`sm 16px border-2 / md 32px border-2 / lg 48px border-[3px] / xl 64px border-4`，转速 0.75s linear；颜色档 primary（默认 text-primary-500）/ gray / white。页面级加载：`flex items-center justify-center py-12`。

**`.skeleton`**：`animate-pulse rounded-lg bg-gray-200 dark:bg-dark-700`；circle 变体 `rounded-full`；text 变体高 1em。

## 15. 分页 Pagination

- 容器：`border-t gray-200/dark-700 bg-white dark:bg-dark-800 px-4 py-3 sm:px-6`（贴表格卡底部）
- 信息区：`text-sm text-gray-700 dark:text-gray-300`，数字 `font-medium`
- 桌面按钮组：`inline-flex -space-x-px rounded-md shadow-sm`，按钮 `border gray-300/dark-600 px-2 py-2`，首/尾 `rounded-l-md`/`rounded-r-md`；当前页高亮 primary；禁用 `opacity-50`
- 移动端（<sm）：只留「上一页/下一页 + 第 x/y 页」
- 每页条数：Select 宽 `w-20`；跳页输入 `.input w-20` + `.btn btn-ghost btn-sm`

## 16. 分隔线与代码

- `.divider`：`my-4 h-px bg-gray-200 dark:bg-dark-700`
- `.code`：行内代码 `font-mono text-sm bg-gray-100 dark:bg-dark-800 rounded px-1.5 py-0.5 text-primary-600 dark:text-primary-400`
- `.code-block`：块级 `font-mono text-sm bg-gray-900 text-gray-100 rounded-xl p-4 overflow-x-auto`（亮暗模式均深底）

## 17. 引导提示盒（tour info box，四色便签）

公式：`rounded-md border-l-4 border-{hue}-500 bg-{hue}-50 px-3 py-2 text-xs text-{hue}-900`（dark：`border-{hue}-400 bg-{hue}-950/40 text-{hue}-200`）。四色：blue(信息)、emerald(成功)、amber(警告)、red(错误)。
