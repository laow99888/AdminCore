# 03 字体与排版

## 1. 字体族（无 webfont，纯系统栈）

```js
// tailwind.config.js
fontFamily: {
  sans: ['system-ui', '-apple-system', 'BlinkMacSystemFont', 'Segoe UI',
         'Roboto', 'Helvetica Neue', 'Arial', 'PingFang SC',
         'Hiragino Sans GB', 'Microsoft YaHei', 'sans-serif'],
  mono: ['ui-monospace', 'SFMono-Regular', 'Menlo', 'Monaco', 'Consolas', 'monospace']
}
```

- 正文/UI：`font-sans`（中文回退 PingFang SC → 微软雅黑）。
- 代码/API Key/数值：`font-mono`。
- 全局开启抗锯齿：`html { @apply antialiased scroll-smooth; }`。

## 2. 字号阶梯（Tailwind 默认档，项目实际用到的全部）

| 类 | 字号/行高 | 字重 | 实际用途 | 出处 |
|---|---|---|---|---|
| `text-xs` | 12px / 16px | 400 / 500 / 600 | 提示、徽章、分节标题、表格辅助 | 全站 |
| `text-sm` | **14px / 20px** | 400–600 | **正文与控件默认字号**：按钮、输入框、表格、导航链接 | `.btn` `.input` `.table` |
| `text-base` | 16px / 24px | 400 | 长文本、大按钮 | `.btn-lg` |
| `text-lg` | 18px / 28px | 600 / 700 | 顶栏页面标题、弹窗标题、空状态标题 | AppHeader、`.modal-title` |
| `text-xl` | 20px / 28px | 700 | 统计卡数值（仪表盘 p-4 变体） | UserDashboardStats |
| `text-2xl` | 24px / 32px | 700 | 内容区页面标题（`.page-title`）、统计卡数值（`.stat-value`） | style.css |
| `text-3xl` | 30px / 36px | 700 | 登录页站名、公告 h1 | AuthLayout |

## 3. 标题层级规范

| 层级 | 规格 | 用在哪 |
|---|---|---|
| 页面主标题（顶栏） | `text-lg font-semibold text-gray-900 dark:text-white` + 可选描述 `text-xs text-gray-500 dark:text-dark-400` | AppHeader 左侧，每页一个 |
| 页面主标题（内容区） | `.page-title` = `text-2xl font-bold text-gray-900 dark:text-white` + `.page-description` = `mt-1 text-sm text-gray-500 dark:text-dark-400` | 独立落地类页 |
| 卡片标题 | `text-sm font-semibold text-gray-900 dark:text-white`（图表卡）/ `text-base font-semibold`（弹窗内分组） | 卡片头部 |
| 弹窗标题 | `.modal-title` = `text-lg font-semibold text-gray-900 dark:text-white` | modal-header |
| 侧栏分节标题 | `text-xs font-semibold uppercase tracking-wider text-gray-400 dark:text-dark-500` | `.sidebar-section-title` |
| 统计卡标签 | `text-xs font-medium text-gray-500 dark:text-dark-400`，数值 `text-xl/text-2xl font-bold` | stat 卡 |

颜色约定：**标题一律 `text-gray-900 dark:text-white`**（注意暗色用纯 `white` 而非 `gray-100`，两种都有出现，新页面统一 `dark:text-white`）。

## 4. 文字颜色阶梯（light / dark 成对出现）

| 用途 | 类 |
|---|---|
| 主文字/标题 | `text-gray-900 dark:text-white`（或 `dark:text-gray-100`） |
| 正文/次要 | `text-gray-700 dark:text-gray-300` |
| 辅助/说明 | `text-gray-500 dark:text-dark-400` |
| 最弱（占位、分节标题） | `text-gray-400 dark:text-dark-500` |
| 品牌强调 | `text-primary-600 dark:text-primary-400` |
| 成功 | `text-emerald-600 dark:text-emerald-400` |
| 警告 | `text-amber-600/700 dark:text-amber-400` |
| 危险 | `text-red-500/600 dark:text-red-400` |
| 行内代码 | `.code` = `font-mono text-sm text-primary-600 dark:text-primary-400`，底 `bg-gray-100 dark:bg-dark-800` |

## 5. 公告 Markdown 排版（announcement-markdown.css，富文本场景参考）

- 正文 `text-[15px] leading-[1.75]`（比 UI 略大、行高宽松）。
- 标题：h1 `text-3xl border-b`、h2 `text-2xl border-b`、h3 `text-xl`、h4 `text-lg`，均带下边距。
- 链接 `blue-600`，`decoration-2 underline-offset-2`。
- 引用块：`border-l-4 border-blue-500 bg-blue-50/50` + 巨型引号伪元素。
- 行内代码：`rounded-lg bg-gray-100 text-pink-600`；代码块 `rounded-xl p-5`。
- 表格：表头渐变 `from-blue-50 to-indigo-50`，行 hover `dark:hover:bg-dark-700/30`。

## 6. 数字与代码

- 金额/配额等关键数字：`font-semibold`/`font-bold` + 语义色（见 02 章）。
- API Key、endpoint：一律 `font-mono`，配合 `.code` 或 `.code-block`（`bg-gray-900 text-gray-100 rounded-xl p-4`，亮暗模式都是深底）。
