# 05 布局系统

## 1. 应用框架总图（登录后所有页面）

```
┌────────────────────────────────────────────────────────────┐
│ bg-gray-50 / dark:bg-dark-950（min-h-screen）              │
│ ┌──────────┐  ┌──────────────────────────────────────────┐ │
│ │          │  │ ▒ fixed 全屏 mesh-gradient 青色氛围层    │ │
│ │ Sidebar  │  ├──────────────────────────────────────────┤ │
│ │ fixed    │  │ Header  h-16 sticky glass z-30 底边框    │ │
│ │ z-40     │  ├──────────────────────────────────────────┤ │
│ │ w-64     │  │ main  p-4 md:p-6 lg:p-8                  │ │
│ │ (收缩    │  │   ┌─ 页面内容（通常 space-y-6）───────┐  │ │
│ │  72px)   │  │   │  统计卡栅格 / 表格卡 / 图表卡    │  │ │
│ │          │  │   └──────────────────────────────────┘  │ │
│ └──────────┘  └──────────────────────────────────────────┘ │
│     ↑ 内容区 lg:ml-64（收缩时 lg:ml-[72px]）               │
└────────────────────────────────────────────────────────────┘
```

关键数值：侧栏 256px（收缩 72px）；顶栏 64px；内容边距 16/24/32px；`lg`（1024px）是侧栏显隐与栅格换档的分界点。

## 4. 内容区与页面骨架

标准数据页结构（`AppLayout` 内）：

```html
<div class="space-y-6">
  <!-- ① 可选：page-header -->
  <div class="page-header">
    <h1 class="page-title">…</h1>
    <p class="page-description">…</p>
  </div>
  <!-- ② 统计卡栅格（有仪表盘时） -->
  <div class="grid grid-cols-2 gap-4 lg:grid-cols-4">…</div>
  <!-- ③ 表格页则用 TablePageLayout（见下） -->
</div>
```

**TablePageLayout（表格页专用骨架）**——flex 纵向布局，高度锁定为一屏：

```css
.table-page-layout { display:flex; flex-direction:column; gap:24px;
  height: calc(100vh - 64px - 4rem); }  /* 减顶栏 + lg:p-8 上下边距 */
/* 四个插槽区：actions(固定) → filters(固定) → table(卡片内滚动 flex-1) → pagination(固定) */
/* 表格卡：bg-white dark:bg-dark-800 rounded-2xl border shadow-sm overflow-hidden */
/* 粘性表头：bg-gray-50/80 dark:bg-dark-800/80 backdrop-blur-sm */
/* 单元格：th/td 均 px-5 py-4 text-sm，th 灰字 med、td 灰字，行底边框 gray-100/dark-800 */
```

移动端（`window.innerWidth < 1024`）自动切换 `.mobile-mode`：容器去边框去阴影、恢复正常文档流滚动。

## 5. 仪表盘栅格（用户端/管理端完全一致）

| 区 | 栅格 |
|---|---|
| 统计卡（两行） | `grid grid-cols-2 gap-4 lg:grid-cols-4`（移动 2 列 → lg 4 列） |
| 统计卡本体 | `card p-4`，内部 `flex items-center gap-3`：图标底座 `rounded-lg bg-{hue}-100 p-2 dark:bg-{hue}-900/30` + 图标 20px stroke-2；右侧标签 `text-xs font-medium text-gray-500`、数值 `text-xl font-bold` |
| 图表卡 | `card p-4`，标题 `text-sm font-semibold mb-4`，图表容器固定 `h-48` |
| 底部 1/3 分栏 | `grid grid-cols-1 gap-6 lg:grid-cols-3`，主内容 `lg:col-span-2` |
| 平台拆分行 | `grid grid-cols-1 gap-3 sm:grid-cols-2 lg:grid-cols-4`，小卡 `rounded-lg border p-3` |

`.stat-card`（style.css 版，内容较多的场景）：`card p-5 flex items-start gap-4`，图标底座 `h-12 w-12 rounded-xl` + `text-xl` 图标，数值 `text-2xl font-bold truncate`，趋势行 `text-xs font-medium`（涨 `text-emerald-600 dark:text-emerald-400` / 跌 `text-red-600 dark:text-red-400`）。

## 7. 响应式断点（Tailwind 默认 + 项目使用习惯）

| 断点 | px | 项目习惯 |
|---|---|---|
| （默认） | <640 | 手机：单列、隐藏次要文字、侧栏抽屉 |
| `sm:` | ≥640 | **第一主力档**（使用 421 次）：两列表单 `sm:grid-cols-2`、显示完整文字、横排 |
| `md:` | ≥768 | 内容边距换档、部分双列（165 次） |
| `lg:` | ≥1024 | **结构分界**：侧栏常显、内容 `lg:p-8`、统计卡 4 列、1/3 分栏、顶栏标题显示 |
| `xl:`/`2xl:` | ≥1280/1536 | 少量定宽收放（36/10 次） |

移动优先：先写手机样式，再逐档加 `sm:`/`lg:`。表格页在 JS 层以 `1024px` 为移动模式开关。

## 8. z-index 层级表（全站 grep 统计整理）

| 层级 | 用途 |
|---|---|
| `z-0`~`z-[3]` | 表格 sticky 表头、底层内容 |
| `z-10` | 背景装饰之上的内容层（登录表单容器等） |
| `z-20` | 次级浮层、popover 关闭钮 |
| `z-30` | 顶栏（sticky）、移动端侧栏遮罩、页面级浮层 |
| `z-40` | 侧边栏 |
| `z-50` | **主力值**（64 处）：弹窗遮罩、下拉菜单、模态内容 |
| `z-[60]` | 高于弹窗的浮层 |
| `z-[100]` | Toast（`fixed right-4 top-4`）、全屏遮罩/预览 |
| `z-[110]~[140]` | 连续递增的弹层阶梯（罕见） |
| `z-[9999]` | 右键菜单、行悬浮 tooltip |
| `z-[99999998]`/`z-[100000000]` | driver.js 引导层（overlay/popover） |

规律：常规 UI 用 Tailwind 标准档 10/20/30/40/50；50 以上走 `z-[100]` 阶梯；特例 9999 系。
