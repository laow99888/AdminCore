# 01 设计系统概览

## 1. 技术栈（决定规范的表达形式）

| 层 | 选型 | 版本 |
|---|---|---|
| 框架 | Vue 3（Composition API + `<script setup>`） | ^3.4 |
| 语言 | TypeScript | ~5.6 |
| 构建 | Vite | ^5 |
| 样式 | **Tailwind CSS**（原子类，无 UI 组件库） | ^3.4 |
| 状态 | Pinia | ^2 |
| 图表 | chart.js + vue-chartjs | ^4 |
| 图标 | Heroicons v2 Outline（内联 SVG，无图标字体） | — |
| 引导 | driver.js（新手引导） | ^1.4 |

要点：**没有引入任何 UI 组件库（无 Ant Design/Element）**。全部组件（按钮、弹窗、表格、开关……）都是自己用 Tailwind 原子类 + `@layer components` 封装的，所以规范 100% 由 `tailwind.config.js` + `src/style.css` 两个文件承载。

## 2. 设计语言关键词

- **主色**：Teal 青色系（`primary`，锚点 `#14b8a6`），贯穿按钮、激活态、焦点环、Logo 光晕、图表。
- **辅色**：Slate 石板灰（`accent`/`dark` 同一套），承担文字、边框、深色模式底色。
- **卡片化**：一切内容装进 `rounded-2xl`（16px）白卡 + 极浅阴影 `shadow-card`。
- **玻璃拟态**：顶栏与登录页用半透明底 + `backdrop-blur-xl`（`glass` 效果）。
- **渐变按钮**：主按钮是 `linear-gradient(135deg, 500 → 600)` 渐变底 + 同色 25% 阴影。
- **明暗双主题**：`darkMode: 'class'`，几乎所有颜色类都带 `dark:` 镜像，是硬性要求。
- **系统字体**：不加载任何 webfont，直接系统字体栈（中文 PingFang SC / Microsoft YaHei）。
- **轻动效**：入场 fade/slide/scale 一律 200–300ms ease-out；按钮按下 `scale(0.98)`。

## 3. 主题机制（做新站必须照抄的部分）

```js
// 1. Tailwind 配置
darkMode: 'class'   // 由 <html> 上的 .dark 类驱动

// 2. 初始化（AppSidebar.vue，应用启动时执行）
const savedTheme = localStorage.getItem('theme')
if (
  savedTheme === 'dark' ||
  (!savedTheme && window.matchMedia('(prefers-color-scheme: dark)').matches)
) {
  document.documentElement.classList.add('dark')
}

// 3. 切换（顶栏/侧栏的主题按钮）
document.documentElement.classList.toggle('dark', isDark)
localStorage.setItem('theme', isDark ? 'dark' : 'light')

// 4. color-scheme 同步（style.css），保证滚动条/原生控件跟随
html { color-scheme: light; }
.dark { color-scheme: dark; }
```

## 4. 源码结构地图（规范都藏在哪）

## 5. 页面体系

- **应用框架**（登录后所有页面）：固定左侧栏（256px，可收缩到 72px）+ 吸顶玻璃顶栏（64px）+ 内容区（`bg-gray-50`/`dark-950`，叠加青色 mesh 渐变背景装饰）。
- **两套角色视图**：用户端（/dashboard、/keys、/usage…）与管理端（/admin/*）共用同一套布局与组件，仅导航项不同——即**只有一种视觉体系，没有管理端特殊皮肤**。
- **独立布局**：登录/注册用 `AuthLayout`（全屏居中玻璃卡 + 光球装饰），不套应用框架。
