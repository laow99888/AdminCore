# 08 图标与图表

## 1. 图标体系：Heroicons v2 Outline

- **唯一图标家族**：Heroicons v2 outline 版，24×24 viewBox，`fill="none" stroke="currentColor"`，`stroke-linecap="round" stroke-linejoin="round"`。
- **默认线宽 1.5**（Heroicons 标准）。统计卡等强调场景显式加粗到 **2**。
- 实装方式：`src/components/icons/Icon.vue` 内联 path 字典（70+ 图标）+ 侧栏等处直接内联 SVG。另有 `@lobehub/icons` 用于 AI 模型品牌图标（ModelIcon 组件）。
- **不使用图标字体、不使用 Emoji 当界面图标**。

### 尺寸档位（Icon.vue size 属性）

| size | 尺寸 | 用途 |
|---|---|---|
| `xs` | h-3 w-3（12px） | 徽章内、极紧凑处 |
| `sm` | h-4 w-4（16px） | 行内、次级菜单（侧栏子菜单）、按钮内图标 |
| `md`（默认） | h-5 w-5（20px） | **标准**：侧栏菜单、按钮、输入框附件、统计卡 |
| `lg` | h-6 w-6（24px） | 空态小图标、突出入口 |
| `xl` | h-8 w-8（32px） | 大图标按钮、特殊场景 |

### 图标使用模式

- 图标颜色永远 `currentColor`（继承文字色），不单独给图标配色。
- 「图标底座」模式（统计卡/平台卡）：图标 + `rounded-lg bg-{hue}-100 p-2 dark:bg-{hue}-900/30 text-{hue}-600 dark:text-{hue}-400` 容器。
- 侧栏菜单图标固定 `h-5 w-5 flex-shrink-0`；子菜单 `h-4 w-4`。
- 图标按钮必须带 `aria-label`。

## 2. 图表（chart.js）配色与配置约定

来源：`src/components/charts/TokenUsageTrend.vue`、`ModelDistributionChart.vue` 等。

### 2.1 序列色（折线/时间序列）

| 指标 | 色值 | Tailwind |
|---|---|---|
| 输入 tokens | `#3b82f6` | blue-500 |
| 输出 tokens | `#10b981` | emerald-500 |
| 缓存写入 | `#f59e0b` | amber-500 |
| 缓存读取 | `#06b6d4` | cyan-500 |
| 命中率 | `#8b5cf6` | violet-500 |

### 2.2 饼/环图 12 色板（按序取用，「其他」固定灰）

```
#3b82f6  #10b981  #f59e0b  #ef4444  #8b5cf6  #ec4899
#14b8a6  #f97316  #6366f1  #84cc16  #06b6d4  #a855f7
其他：#94a3b8（slate-400）
borderWidth: 0
```

### 2.3 折线绘制约定

- 线宽默认，圆滑 `tension: 0.3`；线下填充 = 序列色 + `20` 透明后缀（约 12%，如 `#3b82f620`）。
- 比率类辅助线：`borderDash: [5,5]`，不填充。

### 2.4 坐标轴与文字（深浅模式互换）

| 元素 | light | dark |
|---|---|---|
| 轴文字 color | `#374151`（gray-700） | `#e5e7eb`（gray-200） |
| 网格线 color | `#e5e7eb`（gray-200） | `#374151`（gray-700） |

### 2.5 图例与提示

- 折线图例：`position: 'top'`，`usePointStyle: true` + `pointStyle: 'circle'`，`padding: 15`，labels 字号 **11**。
- 刻度字号 **10**。
- 环图：图例 `display: false`，右侧用 HTML 明细列表代替（色点 + 名称 + 数值）。
- tooltip：`mode: 'index'`，`intersect: false`。
- 容器：`responsive: true` + `maintainAspectRatio: false`，**外层固定高度 `h-48`**（192px）。

## 3. 新增图表时的检查单

1. 序列 ≤5：直接用 2.1 语义分配；>5 或无语义：按 2.2 色板顺序取色。
2. 网格/文字颜色做 `isDark` 判断（或读 `document.documentElement.classList.contains('dark')`），两套都要有。
3. 图表容器写死高度（`h-48`），不要让图表自己撑高。
4. 图例字号 11 / 刻度 10，别用默认 12+。
5. 金额类序列用 emerald-500，警告类用 amber-500，错误类用 red-500，保持与语义色一致。
