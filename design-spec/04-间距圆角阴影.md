# 04 间距、圆角、阴影、边框、玻璃效果

## 1. 间距体系

使用 Tailwind 默认 4px 基数刻度（1 = 4px）。全站高频档位：

| 类 | px | 实际用途 |
|---|---|---|
| `gap-1` / `gap-2` | 4 / 8 | 图标与文字、徽章内部 |
| `gap-3` | 12 | 统计卡内图标与文字、小卡栅格 `gap-3` |
| `gap-4` | 16 | **统计卡栅格间距**、表单行内 |
| `gap-6` | 24 | **页面区块间距**（`space-y-6`）、弹窗 footer 按钮距 |
| `p-2` | 8 | 小容器、tabs 外壳 |
| `p-3` | 12 | 侧栏底部区、平台小卡 |
| `p-4` | 16 | **仪表盘卡片内边距**、表格容器按钮区 |
| `p-5` | 20 | `.stat-card` 标准内边距 |
| `p-6` | 24 | **card-body / card-header / modal 正文**标准内边距 |
| `p-8` | 32 | 登录卡内边距 |
| 内容区边距 | 16 / 24 / 32 | `main: p-4 md:p-6 lg:p-8`（三档响应式） |
| 顶栏水平内距 | 8/16/24 | `px-2 sm:px-4 md:px-6` |

页面纵向节奏：**区块之间 `space-y-6`（24px）**，卡片内标题与内容 `mb-4`。

## 2. 圆角（含使用规律，频率从高到低）

| 类 | px | 用在哪（全站统计得出的规律） |
|---|---|---|
| `rounded-lg` | 8px | **默认控件圆角**：表格内嵌元素、图标底座、小按钮、骨架屏、提示块 |
| `rounded-full` | 9999 | 徽章、状态点、开关、头像、进度条、分页按钮、加载圈 |
| `rounded-xl` | 12px | **按钮/输入框/下拉/Toast/右键菜单/侧栏链接**（交互控件标准圆角） |
| `rounded-2xl` | 16px | **卡片/弹窗/表格容器**（内容容器标准圆角）、Logo 底座、空状态图标 |
| `rounded-md` | 6px | 极小控件（toggle 内按钮、移动端分页按钮） |
| `rounded-4xl` | 32px | 自定义档，罕用 |

记忆口诀：**控件 xl，容器 2xl，药丸 full，卡内小件 lg**。

## 3. 阴影（自定义 7 档 + Tailwind 默认档）

```js
// tailwind.config.js
boxShadow: {
  glass:        '0 8px 32px rgba(0, 0, 0, 0.08)',      // 玻璃卡
  'glass-sm':   '0 4px 16px rgba(0, 0, 0, 0.06)',      // 玻璃卡小
  glow:         '0 0 20px rgba(20, 184, 166, 0.25)',   // 品牌光晕（Logo 底座）
  'glow-lg':    '0 0 40px rgba(20, 184, 166, 0.35)',   // 强光晕
  card:         '0 1px 3px rgba(0, 0, 0, 0.04), 0 1px 2px rgba(0, 0, 0, 0.06)',  // 卡片默认，极浅
  'card-hover': '0 10px 40px rgba(0, 0, 0, 0.08)',     // 卡片悬浮
  'inner-glow': 'inset 0 1px 0 rgba(255, 255, 255, 0.1)' // 深色卡内高光
}
```

| 场景 | 用哪个 |
|---|---|
| 静态卡片 | `shadow-card`（浅到几乎看不见，靠边框分层） |
| 卡片 hover | `shadow-card-hover` + `-translate-y-0.5` |
| 下拉菜单/Toast | `shadow-lg` |
| 弹窗 | `shadow-2xl`（modal）/ `shadow-xl`（dialog） |
| 品牌渐变按钮 | `shadow-md shadow-primary-500/25` → hover `shadow-lg shadow-primary-500/30`（同色染色阴影） |
| 登录 Logo | `shadow-lg shadow-primary-500/30` |
| 危险/成功/警告按钮 | 同主按钮，但换成 `shadow-red-500/25` 等 |

## 4. 边框

- 统一 1px，颜色亮暗成对：**卡片 `border-gray-100 dark:border-dark-700/50`；控件 `border-gray-200 dark:border-dark-600`；分隔线 `border-gray-200 dark:border-dark-700`**。
- 全局基础规则：`* { @apply border-gray-200 dark:border-dark-700; }`（style.css 第一条，任何没写边框色的 border 自动得到这对颜色）。
- 表单报错：`border-red-500 focus:border-red-500 focus:ring-red-500/30`。
- 玻璃卡边框特例：`border-white/20 dark:border-dark-700/50`（半透明白边）。
- 顶栏底边：`border-gray-200/50 dark:border-dark-700/50`（半透明，配玻璃底）。

## 5. 玻璃拟态与模糊

```css
/* 玻璃底（顶栏 .glass） */
background: rgb(255 255 255 / 0.8);           /* dark: rgb(30 41 59 / 0.8) = dark-800/80 */
backdrop-filter: blur(24px);                   /* backdrop-blur-xl */

/* 玻璃卡（登录卡 .glass-card / .card-glass） */
background: rgb(255 255 255 / 0.7);           /* dark: dark-800/70 */
backdrop-filter: blur(24px);
border: 1px solid rgb(255 255 255 / 0.2);     /* dark: dark-700/50 */
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.08);   /* shadow-glass */
border-radius: 16px;                           /* rounded-2xl */
transition: all 300ms;
```

| 档位 | 用途 |
|---|---|
| `backdrop-blur-xl`（24px） | 顶栏、玻璃卡 |
| `backdrop-blur-sm`（4px） | 弹窗遮罩、粘性表头 |
| 自定义 `backdrop-blur-xs`（2px） | 极轻度，罕用 |

遮罩：modal `bg-black/50 backdrop-blur-sm`；dialog `bg-black/40 dark:bg-black/60`；移动端侧栏遮罩 `bg-black/50`；全屏预览 `bg-black/80`。
