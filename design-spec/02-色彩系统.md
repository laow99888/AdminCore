# 02 色彩系统

所有色板来自 `tailwind.config.js`。三套 11 档色阶，命名 `50 → 950`（数字越大越深）。

## 1. 主色 primary（Teal 青色系）

品牌色、交互色。锚点 **500 = `#14b8a6`**。用于：主按钮、链接强调、激活导航、焦点环、进度条、选中文本、Logo 光晕。

| 档位 | HEX | 典型用途 |
|---|---|---|
| 50 | `#f0fdfa` | 激活菜单底色（light）、余额胶囊底色 |
| 100 | `#ccfbf1` | 徽章底、图标底座（light） |
| 200 | `#99f6e4` | — |
| 300 | `#5eead4` | 暗色模式图标/徽章文字 |
| 400 | `#2dd4bf` | 暗色模式强调文字、渐变收尾 |
| 500 | `#14b8a6` | **主锚点**：按钮渐变起点、开关激活、焦点环 |
| 600 | `#0d9488` | 按钮渐变终点、hover 加深 |
| 700 | `#0f766e` | 徽章文字（light）、hover 再加深 |
| 800 | `#115e59` | — |
| 900 | `#134e4a` | 暗色徽章底（常配 `/30` 透明度） |
| 950 | `#042f2e` | — |

## 3. 灰阶 gray（Tailwind 默认，light 模式主力）

项目 light 模式的文字/边框/分隔线全部用 Tailwind 默认 `gray`，出现频次最高：

| 用途 | light | dark |
|---|---|---|
| 页面底色 | `gray-50` `#f9fafb` | `dark-950` `#020617` |
| 卡片底色 | `white` | `dark-800` `#1e293b`（或 `/50`、`/70` 半透明） |
| 主文字 | `gray-900` `#111827` | `gray-100` `#f3f4f6` |
| 次文字 | `gray-700` `#374151` | `gray-300` `#d1d5db` |
| 辅助文字 | `gray-500` `#6b7280` | `dark-400` `#94a3b8` |
| 卡片边框 | `gray-100`/`gray-200` | `dark-700/50`/`dark-700` |
| 表格分隔线 | `gray-100` | `dark-800` |
| 输入框边框 | `gray-200` | `dark-600` |
| hover 行/底 | `gray-50`/`gray-100` | `dark-800/30`~`dark-800` |
| 骨架屏 | `gray-200` | `dark-700` |

## 4. 语义色映射（项目不用自定义语义名，直接用 Tailwind 色相）

| 语义 | 色相 | 标准四件套（徽章/图标底座公式） |
|---|---|---|
| 成功/可用 | `emerald`（资金）与 `green`（状态）并存 | `bg-emerald-100 text-emerald-700 dark:bg-emerald-900/30 dark:text-emerald-400` |
| 警告 | `amber` | `bg-amber-100 text-amber-700 dark:bg-amber-900/30 dark:text-amber-400` |
| 危险 | `red` | `bg-red-100 text-red-700 dark:bg-red-900/30 dark:text-red-400` |
| 品牌/信息 | `primary`（teal） | `bg-primary-100 text-primary-700 dark:bg-primary-900/30 dark:text-primary-400` |
| 中性 | `gray` | `bg-gray-100 text-gray-700 dark:bg-dark-700 dark:text-dark-300` |
| 特色/标签 | `purple` | `bg-purple-100 text-purple-700 dark:bg-purple-900/30 dark:text-purple-400` |

**四件套公式**（全站统一的暗色镜像规则，必须原样套用）：

```
bg-{hue}-100  text-{hue}-700  dark:bg-{hue}-900/30  dark:text-{hue}-400
```

其他约定：进度/配额阈值分档——正常 `primary-500`、≥75% `amber-500`、≥95% `red-500`；成本类数值 actual 用 `purple-600`、渠道成本用 `orange-500`。

## 6. 特殊色彩场景

```css
/* 选中文本 */
::selection { background: rgb(20 184 166 / 0.2); }  /* primary-500/20 */

/* 主按钮渐变 */
background-image: linear-gradient(135deg, #14b8a6 0%, #0d9488 100%);   /* gradient-primary */
background-image: linear-gradient(135deg, #1e293b 0%, #0f172a 100%);   /* gradient-dark */

/* 页面背景装饰（AppLayout 全屏叠加，pointer-events-none） */
background-image:
  radial-gradient(at 40% 20%, rgba(20,184,166,0.12) 0px, transparent 50%),
  radial-gradient(at 80% 0%,  rgba(6,182,212,0.08) 0px, transparent 50%),
  radial-gradient(at 0% 50%,  rgba(20,184,166,0.08) 0px, transparent 50%);  /* mesh-gradient */

/* 渐变文字（登录页站名等） */
background-image: linear-gradient(to right, #14b8a6, #64748b);  /* text-gradient：primary-500→accent-500 裁字 */

/* 登录页背景 */
light: linear-gradient(to bottom right, #f9fafb, rgba(240,253,250,0.3), #f3f4f6)
dark:  dark-950 → dark-900
装饰：3 个 teal 模糊光球 blur-3xl（h-80×2 + h-96，透明度 20%/15%/10%）+ 64px 网格纹理 rgba(20,184,166,0.03)
```
