# 编辑冲突验收矩阵

本批登记的用户、角色、菜单、字典、部门/人员归属/角色数据范围、岗位、示例工单、系统参数、定时计划、公告、消息模板、个人资料及代码生成页，统一使用 `EditConflictPanel` 与 `useEditConflict`：409 保留草稿和读取版本，停用重复保存；仅点击“查看服务器最新值”读取快照，比较不覆盖草稿，仅点击“载入服务器最新值（替换当前输入）”才替换。失败可重试；撤权、模块关闭、切换编辑对象或卸载后，迟到快照不能回填。
