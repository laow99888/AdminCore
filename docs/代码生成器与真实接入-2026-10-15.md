# 代码生成器与真实接入

生成器是本地开发命令，默认只输出文件清单和逐文件差异。它不开放远程执行接口，不自动安装/启用模块，也不自动执行业务迁移。

## 从定义生成

UTF-8 JSON定义示例：

```json
{
  "module": "work_assets",
  "title": "资产记录",
  "model": "AssetRecord",
  "fields": [
    {"name": "label", "label": "名称", "kind": "string", "max_length": 80},
    {"name": "quantity", "label": "数量", "kind": "integer", "minimum": 0, "maximum": 100},
    {"name": "available", "label": "可用", "kind": "boolean", "default": true}
  ]
}
```

在backend目录执行：

```powershell
python manage.py generate_module --definition ../asset-definition.json --output ../asset-preview --plan ../asset-plan.json
```

输出十二个文件：独立后端app、模型/显式字段序列化器/事务服务/API/路由/Module声明、迁移包、前端页面、测试和接入说明。目录不包含自动创建的真实数据库迁移；完成模型审查与显式注册后执行makemigrations并审查迁移。

应用计划时，逐文件重复`--select`；不提供选择不会写入。以下只写模型，其他文件保持原样：

```powershell
python manage.py generate_module --definition ../asset-definition.json --output ../asset-preview --apply-plan ../asset-plan.json --select backend/apps/work_assets/models.py
```

计划包含原文件/生成文件SHA-256，应用时重新渲染、检查所有选中原件后再写入；手工内容或模板变化会拒绝旧计划。必须重新预览并审查新差异，不能绕过。覆写原件保存于目标目录`.codex-validation/codegen-<uuid>`，manifest映射原路径；该目录含原代码，应保持本地私有并排除Git。生成器之间用独占锁避免同目录并发写入。磁盘失败尝试恢复自身修改；检测外部编辑后保留备份与冲突列表，不能自动覆盖外部内容。外部编辑器不遵守生成器锁，应用期间应停止编辑目标文件。

## 从已有表生成

```powershell
python manage.py inspect_business_table company_asset --module work_assets --model AssetRecord --title 资产记录
```

命令只读PostgreSQL结构元数据，不读取业务行，不执行输入SQL或DDL。将JSON输出保存为定义，审查字段标签、默认值、界限后再预览生成；生成与应用都会重新核验当前表结构。已有表模型`managed=False`，不会创建/删除该表。

只支持具有UUID id主键、非空creator_id关联当前用户、非空version整数及version>=1数据库约束、created_at/updated_at时区时间戳的普通表。业务字段支持有界string/text、32位integer、boolean；识别简单整数上下界和文本非空约束。拒绝内部表、额外外键/唯一约束、未知检查约束、自定义触发器、分区表、行安全策略、NULL字段及不支持的类型。旧表原本没有必要约束时先人工评审DDL，不让生成器猜测业务语义。

金额、日期、文件、编码唯一性、多表聚合、业务关系、审批状态机及复杂副作用需要人工建模。本批支持简单模块生成，不能据此声称能够完整转换任意业务表。

## 生成后的实际契约

普通用户默认本人范围，扩展组织策略沿用基座授权。创建者不可注入，创建支持幂等，编辑/删除必须提交读取版本；事务锁后重新检查账户/设备/权限/数据范围。审计与业务原子提交，仅存业务字段摘要。创建者引用PROTECT避免删除用户损坏业务记录；模块默认关闭，关闭保留表、数据及迁移。

前端复用BaseTable/BaseDialog、统一主题、响应式布局、草稿离开保护、禁止重复提交、版本冲突保留输入及重新加载确认；详情使用文本插值。标题/字段标签需接入现有uiMessages翻译。每个生成模型有独立OpenAPI类型名。

模块接入步骤在生成的`docs/generated/<module>.md`：后端INSTALLED_APPS和MODULES显式登记；前端registry显式登记；审查迁移、备份后迁移/bootstrap；按职责给已有角色授予四类权限；显式开启模块。再次生成已登记模块时核对生成器标记及API/页面身份；仍需计划/文件选择，不能自动替换人工代码。
