# 独立演示项目与安全重置

演示是独立项目、独立 PostgreSQL 数据库和独立数据卷，不能在现有业务库中打开开关后播种。仅绑定本机 HTTP；不得将该模板直接公开到公网。不得上传真实资料。

## 创建与使用

在包含本功能的已提交源码目录执行（`--ref` 必须指向包含演示命令、配置和脚本的提交）：

```powershell
python scripts/demo_project.py create D:\AdminCoreDemo --frontend-port 8088 --backend-port 8008 --start
```

目标必须是源仓库之外的新目录。脚本复用项目模板归档机制，不复制源目录实际环境文件、Git 历史、媒体、备份或依赖。每次生成随机 Compose 项目名、数据库名和实例身份；项目归属标签防止接管同名他人资源。生成的 `compose.project.yml` 显式覆盖 backend、worker、beat 的 `DJANGO_ENV` 和 `DJANGO_SETTINGS_MODULE`，避免被原生产编排覆盖。

在新目录执行 `python scripts/project.py up` 启动，`status` 查看，`check` 检查迁移，`stop` 停止且保留卷。默认访问 `http://127.0.0.1:8088`。前后端均只监听本机。

| 账号 | 用途 | 密码位置（仅新项目私有 `.env`） |
|---|---|---|
| demo_admin | 超级管理员，体验完整功能 | ADMINCORE_ADMIN_PASSWORD |
| demo_editor | 文件与工单业务操作，无用户管理和授权权限 | ADMINCORE_DEMO_EDITOR_PASSWORD |
| demo_viewer | 只读账号，工单和用户列表仅见本人 | ADMINCORE_DEMO_VIEWER_PASSWORD |

三个密码各自随机生成，不写入源码、元数据、日志或终端输出。演示账号不要求首次改密；这只适用于隔离演示，不改变普通项目的首次改密要求。邮件、Webhook、短信、备份执行器和图片转换默认禁用，不配置真实供应商或收件人。

## 演示场景

初始化包含三账号与独立演示角色、两级组织示意（总部及两个子部门）、岗位和任职、本人数据范围、字典及品牌参数、已发布公告与草稿、个人通知、消息模板、待审/通过/驳回申请、每人待处理和已完成工单、已完成/失败/取消任务、合成操作与登录日志、可预览图片及回收站文件。不存在自动对外发送、伪造生产发送成功或待重试的真实任务。

重复启动或执行 `bootstrap_admincore` 保留演示用户后续修改，不重复创建场景。初始数据没有覆盖每个字段组合；复杂流程和所有第三方能力仍使用专项验收。

## 重置

**重置会清空本实例的演示数据库，再建立初始场景；本实例演示用户后来创建的数据库记录也会清除。** 执行前确认这个演示项目没有真实资料。在新项目目录，从 `admincore.demo.json` 或 `PROJECT.md` 获取公开实例 ID 后执行：

```powershell
python scripts/demo_project.py reset --confirm-instance <本演示实例ID>
```

宿主脚本先核对项目元数据和 Docker 所有权标签，再停止该演示项目 frontend、worker、beat 和 backend；只通过专属编排运行一次性管理命令。随机确认令牌从容器私有环境中读取，不出现在宿主命令参数中。失败时写入服务保持停止，保留日志和数据现场，避免自动接续未确认状态。

数据库命令必须同时满足：`DJANGO_ENV=demo`、demo 预设、PostgreSQL、本地文件存储、实例格式合法、配置库名与连接实际库名均为 `admincore_demo_<32位实例ID>`、独立随机账号凭据，以及数据库内匹配本实例重置令牌的 HMAC 签名标记。重置另需确认令牌；缺失或不匹配时不会调用 `flush`。未标记且有业务数据的数据库拒绝接管，即使名字看起来像演示库也不允许。并发初始化/重置由 PostgreSQL advisory lock 拒绝重复进入。

重置删除旧数据库会话，使旧 JWT 失效；账号密码恢复为该演示项目最初的独立随机密码。媒体卷和后来上传的文件保留，脚本不会删除任意上传路径或数据卷；如需彻底销毁，应由所有者确认具体项目和卷后单独操作。保留文件不代表数据库仍引用它们。

## 兼容性变化与验证

旧 `bootstrap_admincore --demo` 和 `ADMINCORE_PRESET=demo` 都转交上述安全入口，不再提供固定 `Admin#12345` / `Demo#12345` 播种路径。普通开发库使用这些入口会被拒绝；生产依然在预设解析和初始化命令两层拒绝演示。需要演示时必须使用独立创建脚本。已有普通生产账号、权限和初始化行为不受影响。

单元测试覆盖目标及实际库名不匹配、非 demo / 生产、弱或重复凭据、错误确认、他人签名、未知业务数据拒绝接管、并发锁、完整场景、重复启动保留修改、重置恢复及旧会话删除，以及模板归属和失败不恢复写入者。真实 PostgreSQL / Docker / 浏览器验收由主验收流程单独记录，单元结果不替代实际部署验收。
