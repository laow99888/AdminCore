# 富文本公告与安全渲染

本批为通知公告增加可选富文本格式，并交付可复用编辑器和安全展示组件。历史公告、未指定格式的旧客户端及新建公告默认保持纯文本；纯文本中的 HTML 字样按文字显示。当前状态：已验收并完成本地正式服务升级。

| 交付字段 | 本批约定 |
|---|---|
| 功能范围 | 公告正文支持纯文本、富文本两种格式；常用段落、标题、强调、列表、引用、代码及安全链接；保存草稿、预览、发布和撤回沿用既有流程。图片、附件、视频、表格、任意 CSS 和 HTML 源码编辑不属本批范围 |
| 默认是否启用 | 不新增模块或默认进程；标准预设随 notifications 启用，精简预设关闭公告。新建默认纯文本，需要使用者主动选择富文本 |
| 外部依赖 | 前端本地打包 Tiptap、DOMPurify，后端使用 nh3；均固定正式版本和锁文件。无 CDN、在线编辑服务、额外队列或存储依赖 |
| 权限与数据范围 | 公告管理保留 staff/superuser 和 announcement:read/update/publish 的现有规则；已发布公告供已认证用户读取。后台逐请求及写事务内复核会话/权限，版本冲突与幂等规则不变；审计只记录操作、格式、版本、长度和摘要，不记录正文 |
| 关闭后的行为 | 通知模块关闭后公告 API、菜单入口不可用；数据及新增格式列保留，重新启用可继续读取。迁移仍安装执行，不因关闭模块移除表 |
| 可重复执行的验收条件 | 专项 pytest、Vitest、桌面/手机 Playwright；严格 schema 和迁移检查；独立 PostgreSQL/真实 HTTP 的保存、消毒、发布、幂等和模块重启保留验证；全量回归、构建分包预算及真实远端 CI；正式升级前停写备份 |

## 数据兼容与消毒边界

`Announcement.content_format` 为 `plain` 或 `html`，数据库默认 `plain` 并限制枚举。迁移只添加格式列和约束，不将历史正文转换为 HTML。创建未传格式时为纯文本，编辑未传格式时在锁内沿用当前格式；正文和版本仍遵守现有完整编辑契约。旧前端收到缺少格式的对象时同样按纯文本处理。

富文本原始内容和清洗后的内容均最多 20,000 字符，只有空标签、换行、空白或被禁止的内容会拒绝保存。服务端负责最终消毒和存储规范化，读取再次消毒；幂等缓存的成功响应也执行输出保护。前端在编辑器初始化、粘贴和详情展示处消毒，不能以编辑器本身的解析规则替代服务端边界。

允许的 HTML 标签为 `p`、`br`、`h2`、`h3`、`strong`、`em`、`u`、`s`、`ul`、`ol`、`li`、`blockquote`、`pre`、`code`、`hr` 和 `a`。不允许事件属性、内联样式、class、id、name、图片、表单、嵌入资源、SVG 或 MathML；脚本、样式及相关危险容器连同内部内容清除。链接仅允许绝对 HTTP/HTTPS 地址，拒绝用户凭据、空白和控制字符、相对及协议相对地址和其他协议；链接关系固定为 `noopener noreferrer nofollow`。

此边界防止正文注入主动内容，不保证链接目标可信，也不能防止有权限的编辑者发布误导性文字。公告不是通用文档排版或图片上传通道。其他业务若复用编辑器，仍须在自己的服务端保存与读取边界应用同等策略及权限验证。

## 组件复用

`frontend/src/components/common/BaseRichTextEditor.vue` 接受 HTML 字符串 `v-model`、无障碍名称 `label` 及 `disabled`，在真正使用时加载编辑内核。调用方根据 `ready` 和 `invalid` 事件控制提交；加载失败可重试，不能在内核未就绪或内容超限时保存。直接按路径导入，避免通过全站入口提前加载编辑依赖。工具栏复用 Lucide 图标和现有设计令牌，按钮有名称、状态及触屏尺寸。

`SafeRichText.vue` 接受 `content`、`format` 和 `label`；`plain` 使用文字插值，只有本地白名单消毒后的 HTML 才进入 HTML 渲染。消毒失败不显示原始 HTML。纯文本转富文本先转义再保留换行；有内容的格式切换需确认，富文本转纯文本会移除排版和链接，取消则保留原输入。预览、模式切换和异步编辑加载均受原有未保存、权限撤回和页面离开规则约束。

## 升级与运维

新增数据库列无需转换历史正文。部署前为数据库和媒体生成一致停写快照，构建 backend/worker/beat/frontend 并应用迁移，再核对原账号、角色权限及维护计划配置未改变。无新增环境变量或密钥。回退应用前须先确认旧代码对富文本正文的显示行为；旧版只显示文字时会看到 HTML 标记，不能将丢失格式的结果当作原正文覆盖保存。

实现参考 [Tiptap Vue 3 官方安装说明](https://tiptap.dev/docs/editor/getting-started/install/vue3)、[StarterKit](https://tiptap.dev/docs/editor/extensions/functionality/starterkit)、[nh3 消毒接口](https://nh3.readthedocs.io/en/latest/) 和 [DOMPurify 官方项目](https://github.com/cure53/DOMPurify)。版本、许可和最终检查记录以实际锁文件及下方验收结果为准。

本批精确固定 nh3 0.3.7（MIT）、Tiptap 3.32.0（MIT）和 DOMPurify 3.4.17（选择 Apache-2.0 许可）。Tiptap/ProseMirror 及 DOMPurify 的许可证和版权说明保留在 `frontend/third-party/richtext/`，构建后随静态资源发布到 `/third-party/richtext/`。后端安装包保留自身许可。未引入编辑器付费扩展或外部服务。
