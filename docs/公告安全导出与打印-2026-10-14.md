# 公告、安全导出与当前页打印验收

日期：2026-10-14。状态：本机集成验收进行中，远端 CI 待提交后验证。清单全量仍未完成。

## 功能与边界

| 能力 | 本批范围 | 默认启用、依赖 | 权限与关闭行为 |
|---|---|---|---|
| 通知公告 | 管理员保存草稿、编辑、发布、撤回、再次发布；普通登录用户分页检索及阅读已发布正文，包括之后新建的用户 | notifications 在标准/演示预设启用，精简关闭；仅 PostgreSQL/Django，无新增渠道、依赖包或进程 | 管理须管理员身份及 announcement:read/update/publish；普通阅读须有效登录。新权限仅登记，不自动授予已有角色。通知模块关闭时 API/路由/菜单撤下，记录及表保留，重新启用可读 |
| 安全导出 | users、roles、三类 logs、files 元数据 CSV/XLSX；目录 API 独立声明 importable/exportable | data_io 启用且依赖 files/tasks；标准启用、精简关闭。本次导出同步执行，不创建队列任务 | data_io:export 加 user:read/role:read/log:read/file:download；复用对象范围。关闭后入口撤下，无导出落盘或清理任务 |
| 打印/保存 PDF | 用户、角色、文件、日志四页打印当前已加载页，显式安全字段 | 无新增模块、服务或第三方包；对应资源页面可访问时启用，依赖浏览器弹窗与原生打印 | 使用页面原读权限；空/加载状态禁用。离开页、权限/身份/模块/数据变化关闭自建窗口；浏览器已保存的文件无法远程收回 |

公告纯文本标题最多 200 字、正文最多 20,000 字。已发布内容先撤回再编辑；编辑及状态转换携带版本，冲突 409，保留当前输入。成功幂等结果保留 24 小时；相同键不同请求拒绝，失败可重试，重放前重新鉴权。事务锁操作者并复核账号停用、强制改密、会话版本与管理权限，审计失败整体回滚。公告读取/写入/拒绝响应及导入导出能力目录统一 `private, no-store`，避免撤回或身份变化后复用浏览器缓存。审计仅记录版本、状态、正文长度及摘要。

公告与个人通知分开，不逐人生成通知，不影响个人未读数。本批无富文本、阅读回执、邮件、定时发布、公告删除 API；发布时间是实际发布时刻。

导出使用已成功加载的筛选条件，加载中或加载失败禁用。users 保留原有导入；roles/logs/files 明确只支持导出，导入、模板、任务重试及消费者均拒绝。这项原清单“导入导出资源补齐”仍为部分完成。

导出每次最多 5,000 行、10 MiB，单元格最多 32,767 字符；超限整体拒绝，不返回截断文件。CSV/XLSX 都防公式注入。用户沿原导出合同排除管理员账号及密码；角色仅元数据，无权限授予信息；文件排除原始路径、头像与软删除记录。日志仅审计元数据，不导出描述、错误信息、traceback、请求路径或 user agent；日志搜索可以筛选原内容，但下载不含原内容。

打印更窄的字段白名单不等于批量导出：用户仅用户名/邮箱/姓名/启用状态；角色仅名称/描述/启用状态；文件仅名称/类型/大小/上传人；日志仅时间/操作/资源/状态码或用户名/结果或异常级别。最多当前页 100 行、20 列、单项文本 10,000 字、总 HTML 1,000,000 字符，超限不静默裁剪。纯静态文档全面转义，无 DOM 截图、URL、脚本或外部资源，独立 CSP；先切断 opener 再写入。原文档被外部导航替换时只结束自己的会话，不关闭外部页面。

PDF 使用浏览器“另存为 PDF”对话框，无服务器 PDF 生成；自动测试验证打印文档、CSP 与生命周期，未替用户操作系统对话框保存实物 PDF，也未证明全部打印机/字体组合的排版。浏览器无 Save as PDF 功能或禁止弹窗时会提示失败，可重试。
