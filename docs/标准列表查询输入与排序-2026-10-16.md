# 标准列表查询输入与排序

## 功能范围和兼容变化

标准 `list` 入口统一限制查询参数：允许分页、资源已声明的过滤字段、已启用的搜索/排序和显式资源选项；未知参数、重复键、解码后单值超过200字符、NUL字符均返回400。排序最多5项，只允许 `ordering_fields` 中的字段；支持逗号和降序前缀，同一字段重复或混合正反向重复均拒绝。空搜索、空排序及合法Unicode保留支持。

这是输入契约收紧：过去被忽略的未知参数、重复键和非法排序现在明确返回400。调用方升级时须删除多余参数，并检查资源OpenAPI声明；不能用重复键传多选值。过滤值类型继续由资源的 DjangoFilterBackend 处理，本批不宣称统一所有字段的类型转换规则。

通用分页仍默认10、最多100；`page_size` 为0、负数或非数字时保留回退10，超过上限截断，非法页码仍404。DRF既有搜索语义不变。没有显式开放客户端排序的会话列表继续使用服务端固定顺序。

排序末尾补充主键；已经包含主键时保留其方向。在数据集不变时，同值记录跨页顺序稳定；不提供并发写入下的跨请求快照或游标分页保证。详情、自定义action、选择器、回收站及导出沿用各自契约，不自动套用本次输入校验。

## 接入与启停

| 验收项 | 约定 |
| --- | --- |
| 默认状态 | 标准列表默认生效，无新开关；新生成模块继承同一机制 |
| 外部依赖 | 现有Django/DRF与数据库，无新软件包或迁移 |
| 扩展方式 | `QueryBudgetListMixin`；显式声明过滤/搜索/排序字段，额外枚举选项登记 `list_query_choices` |
| 权限与数据范围 | 原认证及权限先执行；再校验输入，然后在原范围查询上排序，不扩大可见对象 |
| 资源选项 | 审批box仅空/todo/done/sent；通知scope仅空/all，普通用户传all仍只见本人 |
| 关闭模块 | 原模块开关继续拒绝入口并保留数据，不因查询机制自动启用模块 |
| 错误与文档 | 400使用统一中英文响应；OpenAPI注明400/503、排序白名单和字符串长度 |

公告原来在构造查询时鉴权，本批将读取鉴权前移至权限检查，保留未登录401、无权限403和新鲜账户/模块检查，避免无效参数提前遮盖拒绝结果。
