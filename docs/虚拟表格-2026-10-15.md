# 可选虚拟表格

状态：已验收（日志列表与独立通用组件的限定范围；清单整体继续实施）。

| 契约 | 本批范围 |
|---|---|
| 功能范围 | 独立通用固定行高虚拟表格，日志三类列表显式切换使用，保留操作日志审计详情、分页和本地/服务端导出。仅渲染可见行及少量缓冲，支持横向滚动、行号、文本列及操作插槽。 |
| 默认是否启用 | 默认普通表格，仅当前页面内选择启用；虚拟组件按点击懒加载，不保存跨账号偏好。 |
| 外部依赖 | 复用已固定Element Plus 2.14.7内Table V2，无新增库或服务。上游该组件仍标记beta，限定封装范围并提供普通表格回退，升级须专项回归。 |
| 权限与数据范围 | 使用原日志API读取范围和分页上限，不额外读取全库。独立组件不发送请求、不创建权限、缓存或持久化数据；调用方须保证输入已授权。 |
| 关闭后的行为 | 普通表格恢复、查询和分页不变；离开/失活/权限改变清除旧行与滚动上下文，不增加后台任务或外部依赖。 |
| 验收条件 | 真实浏览器10000行固定数据滚动到首/末及键盘导航，DOM行数有界；三类日志入口切换、分页、审计、失败/空/加载、撤权和手机/深色/英文；原全量测试和分包预算。合成大数据只验证渲染，不承诺公网吞吐或内存无限。 |

上游依据：[Element Plus虚拟表格](https://element-plus.org/en-US/component/table-v2.html)。固定行高不支持自动换行、合并/树形/拖拽行和批量勾选；使用普通表格处理相应场景。分页仍控制网络和内存量，虚拟滚动不承担全量下载。

二开接入时直接异步导入，不放入通用组件的静态导出入口：

```ts
const BaseVirtualTable = defineAsyncComponent(() => import('@/components/common/BaseVirtualTable.vue'))
```

调用方传入已完成读取权限与字段脱敏的 `data`、白名单 `columns`、区域名称 `label`，以及身份/筛选/分页组成的 `contextKey`；变更上下文、数据或加载状态会重置滚动。行键必须为唯一且非空的有限数字或字符串，数字 `1` 与字符串 `"1"` 也视作冲突；不合格输入显示错误并允许切回普通表格。文本插值不执行 HTML，操作列由可信组件插槽提供。组件不自行取数或持久保存业务数据。

键盘焦点在表格区域自身时支持上下方向键、PageUp/PageDown、Home/End，操作按钮保留原生焦点与事件；区域有名称和忙碌状态。此封装不声称已完成所有屏幕阅读器/复杂网格交互认证。小屏保留固定列宽，在表内横向滚动，不能通过把所有列挤到屏幕内来牺牲可读性。
