# 在线表单授权附件深化（2026-10-18）

本批为在线表单 V2 接入真实授权附件：顶层或明细的 `file` 字段可以选择已有文件、上传后选择、查看原文件名、下载和预览。附件采用具体文件 UUID，随记录的冻结定义解释，后续文档版本或表单新版不会替换旧记录的原文件。授权业务关联选择仍需深化；记录审批闭环见[在线表单审批深化](在线表单记录审批深化-2026-10-19.md)。

## 定义与使用

设计器提供附件字段；一个字段保存一个文件 UUID，需要多个附件时可放入明细多行。附件不允许默认值、选项、长度、金额范围或计算声明；条件显隐、条件必填只允许判断附件为空或非空，不能比较文件 ID。服务端保存及发布重新验证，绕过设计器提交也会被拒绝。

选择器使用已保存表单 ID 或本人记录 ID、表单编码和字段路径取得上下文。未保存或未保存的新附件字段须先保存才能选择。新增运行页使用当前发布版本；历史记录始终使用自己的 `definition_snapshot`，包括明细路径。整表只读时仍可查看有权限的原附件，不能上传或搜索其他文件。

试填携带已授权表单 ID，服务端从数据库确定租户；不接受客户端租户参数决定文件范围。平台管理员未选择租户时也按该表单的实际租户核验；选择了其他租户、表单不存在或缺少管理权限时拒绝。无附件的原有试填调用保持兼容。

## 权限与并发

附件同时要求在线表单上下文权限、启用文件模块、`file:read`、当前文件 ACL 和精确租户一致性。普通记录只允许本人访问；只读历史解析只接受该记录该字段实际绑定的文件，不能借记录读取权限搜索其他文件。仅返回 ID、原文件名、类型和大小，不暴露存储地址。上传完成后再次经过目标上下文和 ACL 解析，不能直接信任上传返回值。

提交和修改在事务内锁定文件并复核状态及 ACL，拒绝已删除、跨租户、私有无权限或非普通用途文件。附件绑定与文件删除使用同一文件行锁，真实 PostgreSQL 测试覆盖绑定先获得锁和删除先获得锁的两种顺序。记录版本冲突不会增加附件引用。

控件遇到用户、令牌、权限、租户、上下文、字段值或父表单禁用状态变化时，立即清除文件信息、预览和候选项并使未完成请求失效。迟到的查询或上传结果不能恢复旧租户文件名，不能写回字段。加载失败有错误提示和重试；不可访问的旧附件显示不可用说明。

## 历史保护与迁移

`OnlineFormFileReference` 按记录与文件保留首次引用版本和字段路径，同一文件在同一记录中只登记一次。更新记录移除附件不会删除历史引用。文件删除入口可查询引用并返回冲突，数据库外键 `PROTECT` 同时阻止直接硬删除文件或记录后破坏引用。

迁移 `online_forms.0003_attachment_references` 只增加引用模型，不猜测历史普通文本中的 UUID，不回填未经授权的附件关联，也不改写存量记录数据、冻结定义、表单版本和记录版本。V1 表单保持原字段协议。
