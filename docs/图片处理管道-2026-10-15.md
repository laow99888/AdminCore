## 使用与接口

文件列表对有双权限的用户读取 `GET /api/v1/files/processing_config/`，配置开启才显示“图片处理”。选择普通图片，填写最大宽高、格式和质量，可上传水印，点击“生成预览”，确认结果后“下载处理结果”。尺寸是包围盒，不会拉伸或放大。PNG 使用无损编码；JPEG 的透明区域铺白底。质量和缩略可能降低体积，但不承诺所有输入都变小。

`POST /api/v1/files/{id}/transform/` 接受 JSON（无水印）或 multipart（带水印）：

```json
{"lifecycle_version":1,"width":1280,"height":1280,"format":"webp","quality":80,"opacity":60,"position":"bottom-right"}
```

multipart 的可选 `watermark` 是图片文件。拒绝未知字段、重复 form 字段、非对象 JSON 和非法选项。必须提交所选文件的生命周期版本，发生恢复/删除等版本变化时返回409。接口不接受路径、远程图片地址、SQL、任意编码器或外部命令。

源文件实际读取最多10 MiB加1字节，像素最多1600万；支持 JPEG/PNG/GIF/WebP/BMP/ICO，仅首帧。宽高1–4096，质量40–95。水印实际内容需为PNG/JPEG/WebP，最多512 KiB、1024px、100万像素，不放大且至多成品宽/高四分之一；不透明度10–100。可用带中文的水印图片，不依赖服务器字体，不提供任意文字排版或矢量水印。

重编码前校验真实格式和像素、应用 EXIF 方向，删除 EXIF/ICC/注释等元数据及附加内容。结果写入受限内存流，最多10 MiB；超限失败，不返回部分图片。未使用磁盘派生缓存、临时外部文件或公共对象地址。超限/损坏/不支持分别给出413/422/415，存储异常503且不回显地址或凭据。结果大小和限制是单请求边界，不代表已经验证大规模图片服务的吞吐或峰值内存。

## 并发、审计和前端生命周期

事务按用户→原 JWT 设备→文件行加锁，锁等待后读取当前账号、设备、双权限、数据范围、普通文件状态和版本；编码后再查设备、双权限、范围及模块开关。用户/文件行锁阻止参与同一锁约定的删除或账号撤销穿过处理事务；角色/范围可独立更新，所以在公开结果前额外复核。已开始发送的响应不承诺被撤权远程销毁。

成功结果与 `file_transform` 结构化审计同事务，审计失败不给出图片。只记录原件/水印/成品SHA-256、原件编号和版本、输出实际宽高/格式/质量、水印位置/不透明度及成品大小，不记录原件/水印字节、文件名、存储路径或上传请求体。处理是只读派生，不增加原文件下载计数或生命周期版本，也不创建可靠事件或后台清理计划。

结果只在当前窗口持有 Blob URL，所有响应 `private, no-store`、`nosniff`、sandbox和DENY。表单变动即释放旧结果，取消请求/关闭/卸载中止读取，迟到响应不恢复结果；新登录设备、权限或模块失效清空草稿。修改参数或水印后的关闭、离开页面遵守既有未保存守卫，失败保留参数并允许重试；处理中禁止重复生成，可单独取消请求。客户端取消不承诺中断已进入 Pillow 的服务端处理，服务端仍受输入/像素/输出上限及部署超时约束。下载到用户设备后的文件由用户管理。

使用项目固定Python与Node/npm版本，在backend目录运行`python -m pytest`；frontend运行`npm run lint`、`npm run test:typecheck`、`npm run test`、`npm run build`、`npm run check:bundle`、`npm run test:e2e`。独立链路在仓库根目录运行：

```powershell
backend/venv/Scripts/python.exe -X utf8 scripts/validate_storage.py
backend/venv/Scripts/python.exe -X utf8 scripts/validate_images.py
```

后者保留18460/18461供本次随机隔离项目使用，创建独立数据库、镜像、卷和随机密码，不读取正式登录密码。真实浏览器覆盖登录、最大尺寸、水印上传、实际成品尺寸、下载、桌面/手机布局、放弃草稿取消与确认；SQL覆盖锁等待期间账号停用、原设备撤销、任一处理权限撤回、范围撤回、版本变化及删除。能力关闭/开启/再关闭/重新启用期间原件摘要保持一致。

成功停止并移除仅本次容器/卷和随机凭据，保留日志/报告/截图。失败停止本次容器并保留证据。此前失败的原有综合验收项目ec950500遗留worker已按精确容器ID停止，保留其报告和卷；未操作正式六服务以外的共享服务或用户数据。
