# 文件基础在线预览

本批交付图片与常规 PDF 预览，默认随文件模块启用。Office 转换、复杂 PDF、OCR、全文检索、打印导出仍是独立待办，不能据此认为整份缺口清单已经完成。

## 行为与边界

- 文件列表提供预览按钮。不支持的类型及超过 10 MiB 的文件禁用预览，原下载入口继续可用。
- `GET /api/v1/files/{id}/preview/` 与原下载接口使用同一 JWT、文件模块开关和文件数据范围：普通用户默认只访问自己的文件，已有角色数据范围继续生效，管理员按既有规则访问。没有新增角色授权或公开媒体 URL；未登录 401，范围外/软删除 404。恢复后可重新预览。
- 前端通过共享 Axios 实例携带认证头，沿用 401 刷新重放，不在 URL 放入令牌。成功预览记录 `read` 审计，不增加下载计数。
- PNG/JPEG/GIF/WebP/BMP/ICO 校验扩展名与实际格式，并解码重编码成 PNG，移除元数据与尾随内容。GIF/多帧图片只显示第一帧；SVG 不直接渲染。
- PDF 用 pypdf 严格解析，校验边界、页数、页面尺寸及有界对象图；拒绝加密、脚本、附件、表单、外部动作、音视频等主动内容，含间接引用的动作类型也拒绝。浏览器使用 PDF.js 独立 worker，仅绘制当前页 canvas，不启用脚本、表单、附件或注释交互。
- 限制写在 Django 基础设置：输入/图片重编码结果最多 10 MiB，图片最多 1600 万像素，PDF 最多 100 页，页面每边最多 14400 pt，对象图最多 20000 次访问/100 层；客户端每页画布最多 400 万像素。复杂编码或绘制失败会显示错误并允许重试/下载。
- 成功响应指定实际 MIME、`inline` 固定安全文件名、`private, no-store`、`nosniff`、沙箱 CSP 和禁止嵌入头。原文件内容不会以 HTML、SVG 或 iframe 展示。
- 关闭弹窗/切换文件/卸载页面会取消请求、销毁 PDF worker/画布并释放图片 Blob URL。预览数据不存入持久缓存。已交付浏览器的内容遵循下载同样的访问时点规则，撤权不能远程收回已读取字节。
- 支持加载、错误、重试、禁用、翻页、窄屏和英文文案。PDF canvas 是页面图像，界面明确提示辅助阅读/文字检索下载原文件；尚未提供 PDF 文本层或屏幕阅读器文档导航。

## 依赖与部署

pypdf 固定 6.20.1（BSD-3-Clause），pdfjs-dist 固定 6.4.299（Apache-2.0），Pillow 复用 12.3.0；后端哈希锁和 npm 锁同步更新。PDF.js、worker、CMap/字体/解码资源从本站提供，许可证随资源发布，不使用 CDN。当前关闭 WebAssembly 优化，无需放宽 `unsafe-eval`/`wasm-unsafe-eval`；复杂编码兼容性按实际绘制结果判断。

渲染器按需分包，登录页和普通文件列表不加载 PDF 渲染器/worker。Nginx 为 `.mjs` worker 显式配置 JavaScript MIME；SPA CSP 仅允许同源 worker，保留脚本同源限制及禁止对象嵌入。本批不涉及数据库迁移或正式文件转换，也不重新分配用户角色。

## 验收方式

- 后端真实解析测试覆盖图片格式/重编码/元数据移除、动图第一帧、PDF 正常/损坏/截断/加密/主动内容/间接动作、大小/像素/页数限制、私有鉴权/越权/软删恢复、安全头、存储缺失/故障脱敏。
- `scripts/validate_storage.py` 使用随机凭据独立 MinIO 实例，新增真实 S3 图片/PDF 预览、越权拒绝及软删/恢复链路，不依赖 `.path`；既有备份恢复、迁移、清理仍须通过。
- `scripts/validate_foundation.py` 使用独立 Docker/PostgreSQL/本地存储项目，验证真实 HTTP 预览、安全头、匿名拒绝、Nginx worker MIME 和生产 CSP，继续运行模块启停、并发和既有基础验收。
- Playwright 新增 7 场景 × 桌面/手机：真实 PNG Blob、真实两页 PDF worker/字体/像素颜色、生产 CSP、按需加载、翻页、资源释放、取消、错误重试、不支持类型、401 自动刷新重放及英文暗色解码失败恢复。API 使用隔离 fixture，PDF 渲染运行真实构建，不以模拟 canvas 替代。
- Vitest 验证认证实例/取消信号、二进制 MIME/大小边界和 Blob 错误原因；既有基础组件覆盖率仅代表其登记范围。执行全量前后端测试、lint、类型、构建和 bundle 预算，严格 OpenAPI 校验与迁移检查。

用户人工登录正式环境仍未进行；真实 AWS/OSS 和 Office 转换未纳入本批验收。
