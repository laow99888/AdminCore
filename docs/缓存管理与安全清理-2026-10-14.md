# 缓存管理与安全清理

| 字段 | 本批约定 |
|---|---|
| 功能范围 | 系统参数和字典两个固定命名空间的当前数据库版本缓存清理；目录、影响预览、120 秒签名确认、执行结果与审计。每个命名空间单次最多 1,000 个候选键，超限拒绝操作；不扫描 Redis、不展示缓存值或原始键，不开放任意前缀或全库清空。历史版本缓存按已有 300 秒 TTL 自行过期。 |

预览展示的是数据库推导的候选键数量，不是 Redis 实际存量、删除数量或内存占用。签名确认期间数据库版本变更则返回冲突并要求重新预览；并发读取可能重新写入缓存，清理不是暂停业务，也不承诺缓存持续为空。缓存和审计数据库不能跨存储原子提交：先持久化未确认操作，再执行限定删除并记录结果；缓存故障可能已部分完成，不报告确定成功。

## 执行边界

- 只登记五项白名单系统参数的已有数据库记录，以及字典当前版本（包含停用字典）；没有记录时不访问缓存服务。历史版本依照原有 TTL 过期，不支持任意键、前缀或全库删除。
- 确认令牌绑定操作者、会话版本、命名空间、数据库版本摘要和缓存后端类型，120 秒后失效；数据库变化或换会话后要求重新预览。令牌只保留在当前页面内存，取消、执行或离开页面即丢弃。
- 同一有效预览允许安全重复删除同一组缓存键，不宣称一次性令牌或业务幂等重放。执行期间禁止再次点击、取消或 Escape 关闭；失败后必须重新预览。
- Redis 删除结果无法确认（包括部署启用异常抑制时返回空结果）则返回 503；审计保存失败时也不报告成功。底层可能部分完成，需按页面提示重新预览。新操作先保存未确认审计，避免先删除后才尝试留下记录。
- 入口使用独立进程内限流，每个用户每进程每分钟 20 次；不依赖故障的 Redis，也不宣称分布式总限额。共享 Django Redis cache 设置连接/读写 socket 超时均为 2 秒，这不是 HTTP 总耗时上限，未改变队列客户端配置。
