| 默认是否启用 | minimal/standard/demo 全部默认关闭。明确启用 realtime 模块并叠加 compose.realtime.yml；默认六服务部署不增加进程。 |

## 启用与关闭

标准部署：如已有显式 ADMINCORE_MODULES，将 realtime 加入该列表；未显式设置时可选编排使用七个标准模块加 realtime。

```powershell
docker compose -f docker-compose.yml -f compose.realtime.yml up -d --build
```

仅需安全核心和 SSE 的精简项目：.env 设置 ADMINCORE_MODULES=realtime，按以下顺序叠加；不启动 Redis/Celery。

```powershell
docker compose -f docker-compose.yml -f compose.minimal.yml -f compose.realtime.yml up -d --build db backend frontend realtime
```

API 为同源 GET /api/v1/realtime/events/，SSE 事件 snapshot 的 data 为 {request_id, topics}，topics 只含当前允许的 notifications/approvals/tasks。task.active 最多最近更新的 20 条正在执行记录；列表实际行及最终结果仍通过分页 API 获取。无权限/模块未启用的 topic 缺席；客户端每次快照更新对应徽标/列表，不能把原值保留成“仍有权限”。heartbeat 是注释帧。access_revoked 终止连接并触发现有会话复核/refresh，unavailable 结束流并退避重连。普通页面请求的 Axios refresh 协调保持原实现。

关闭时先移除显式模块列表的 realtime，再以默认编排更新 backend/frontend/worker/beat，最后通过可选编排 stop realtime。仅停止 SSE 容器但仍保留模块配置，会显示连接失败并回退轮询；不等同完成模块关闭。依赖或代理漏配时 WSGI 入口返回 503，避免长连接占用同步 worker。

## 有界运行和生命周期

- SQL 锁顺序用户→设备会话→全局预算。有效连接全局最多 100、每用户最多 3、每设备会话最多 1；多标签共享设备会话时只有一个标签连接，其他标签回退轮询。128 个 ASGI 并发连接是进程协议上限，不代表百连接容量已压测。
- 租约最长 35 秒，正常断线/完成立即按租约 UUID 释放。旧连接清理不能删新连接。强制崩溃后过期租约不占额度，不删除其他人的租约或业务记录；旧行随 AuthSession 保留/清理级联，备份恢复保留过期行不影响准入。
- PostgreSQL 每条查询 3 秒、锁等待 2 秒、事务 5 秒限制；快照等待最多 5 秒，慢客户端每次发送最多 5 秒。网络故障、数据库失败或过载结束流并恢复轮询，错误不回显异常正文。设置依赖项目固定 PostgreSQL 18；其他数据库需另行验收。
- 浏览器只向同源发送凭据，隐藏/离线/卸载立即 abort，重新可见/联网重连；单帧最多 64 KiB，12 秒无字节超时。失败指数退避至 60 秒，429/503 至少等 60 秒；正常轮换有小幅抖动。事件内容解析白名单，不执行任意事件名/HTML。
- 可见页面保留 60 秒轮询；身份、权限、模块及卸载变化清空或阻止迟到列表响应，刷新列表不覆盖审批编辑草稿。浏览器事件仅携带脱敏摘要，无 token；同源恶意脚本仍属于原 XSS 防护边界，事件不是额外授权证明。
- 本服务 /health/ 是进程与模块存活检查，不代替原后端 DB/Redis 就绪检查；启动先等待后端健康。HTTP 200 已开始后不能修改状态码，因此撤销/故障用白名单 SSE 终止事件。
