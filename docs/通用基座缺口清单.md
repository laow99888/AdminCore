# AdminCore 通用基座缺口清单

**生成日期**：2026-10-13
**修订日期**：2026-10-14（GLM 原清单基础上，经用户确认补充机制、验收要求及岗位/人员选择器、导航体验、缓存管理、表格密度/水印/错误恢复及主题/快捷键/表单保护及公告/安全导出/当前页打印状态）
**定位**：供多个独立项目复用的通用中后台基座，参考若依等项目的常用能力；不默认采用多租户。
**核心理念**：可以不用，但不能没有。底座提供完整能力，小项目按需启用；关闭的模块不增加业务入口、后台任务和不必要的运行依赖。

**范围约定**：P0 为共享机制与扩展契约，P1 为底座计划提供的通用功能，P2 为需要具体业务信号的架构扩展，P3 为持续工程建设。优先级表示实施顺序，不等于全部默认启用。P2 保留规划与扩展边界，不以接口占位宣称功能已完成。

- [ ] 会话分别支持整体撤销和指定会话撤销，定义活动时间、绝对/空闲过期和权限更新时限；撤销后旧 access/refresh 按承诺时限失效。
- [ ] 定时任务只能选择已注册任务和允许参数；重试、超时、重叠、失联、取消及人工重放都有明确语义和权限。
- [x] 缓存清理只作用于登记的参数/字典当前版本键，拒绝任意键/前缀与全库清空；真实 Redis 验证另一命名空间及锁/会话/限流保护键保留。预览绑定身份/会话/数据库版本，权限复核、上限及未确认审计已验收。新增业务范围需另行登记；见缓存管理验收。
- [ ] Webhook/第三方对接定义目标地址校验、网络访问边界、超时、签名、重放防护和密钥轮换，不能成为任意内网访问入口。
- [x] 服务/系统信息页仅管理员及对应只读权限访问，既有角色不自动扩权；白名单返回且禁止缓存，无凭据、环境变量、连接地址、真实路径、主机名或命令行。匿名健康检查只保留就绪结果，诊断匿名访问拒绝；模块关闭返回 404。见系统信息与服务监控验收。
- [ ] 日志串联 HTTP 请求、异步任务和通知记录；提供失败定位与队列指标。关闭诊断模块时，基础错误记录和安全审计仍可用。
- [ ] 代码生成器生成符合本项目权限、数据范围、审计和测试约定的代码；输出可预览、可比较、可选择覆盖，不能静默覆盖人工代码。

## 新增：每项能力的统一交付与验收模板

开展实现前，每项能力必须填以下六项；实施中使用“未开始/进行中/待验收/已验收/部分完成”，不能只标完成百分比。

| 字段 | 必须记录的内容 |
|---|---|
| 功能范围 | 用户能做什么、页面/API/后台处理、边界和本次不覆盖项；现有能力与待实现内容分别写明 |
| 默认是否启用 | 精简/标准/演示预设的选择，启用入口及重启/构建要求 |
| 外部依赖 | 依赖模块、运行进程、数据库/队列/存储/邮件等服务及失败处理；占位适配器不能计为实现 |
| 权限与数据范围 | 操作权限、对象/字段/数据范围、后台任务身份、审计与敏感信息处理 |
| 关闭后的行为 | 路由/菜单/任务/消费者是否停止，数据如何保留，依赖如何处理，重新启用及迁移行为 |
| 可重复执行的验收条件 | 命令/操作步骤、输入和预期结果、测试环境、证据路径、已知限制、验收提交及日期 |

**共同验收门槛**：

- 新空库初始化、已有数据升级、启用/关闭/重新启用均通过；不可逆迁移提前说明并有备份/恢复方案。
- 正常、空数据、加载、错误、禁用、越权、重复请求和并发冲突有对应验证；第三方依赖故障行为可验证。
- 涉及页面时验证桌面/窄屏、主题、语言和键盘可访问性；涉及外部渠道时至少验收一种真实可运行实现，模拟测试另行注明。
- 对新增模块运行针对性测试、类型检查、构建及迁移/schema 检查；更新真实远端 CI，不能只以本地通过计为远端成功。
- “已验收”记录代码提交及证据；一次性能基准、局部组件覆盖率和脚本存在不能替代持续压测、全站覆盖或自动调度验收。

## 落地路线建议（修订批次）

| 批次 | 内容 | 验收重点 |
|---|---|---|
| 第 1 批 | 数据权限/组织模型 + 模块契约/启停预设 → SysConfig/字典/品牌 | 统一鉴权覆盖完整链路；精简项目无需启用全部模块 |
| 第 2 批 | 并发/幂等 + 可靠事件/通知渠道 + 存储适配 + 数据生命周期/回收站 | 幂等、站内 outbox、本地/S3 协议存储、可选软删除与文件回收站已完成当前范围；邮件/Webhook 渠道、其他资源生命周期接入仍待实施 |
| 第 3 批 | 邮件/找回/首次改密/个人资料 + 会话设备 + 导航体验 + 基础预览 | 补齐原始需求；权限变更及会话撤销实际生效 |
| 第 4 批 | 定时任务 UI + 自动备份/告警/清理 + 诊断监控 + 实时通道 + 2FA | 注册任务边界、取消/重叠/失联语义、依赖故障及恢复演练 |
| 第 5 批 | 导入导出资源补齐 + 公告/富文本 + 代码生成器 + 完整二开示例/初始化模板 | 生成和扩展模块遵守权限、审计、测试契约；已有项目可同步升级 |
| 长期 | P2 按业务信号决策，P3 持续穿插，补齐 P1 剩余可选启用功能 | 每项有验收证据，不能以接口占位代替能力交付 |

**工作量说明**：原稿 P0+P1+手册模板约 5–6 人月、P2 再加 3–4 人月，为未经详细拆解的粗估。此次新增机制、兼容迁移与验收范围后，不沿用为承诺；每批设计明确后重新估算。组织权限、软删、会话和存储迁移均可能影响已有数据，不能作为低风险纯页面工作。
