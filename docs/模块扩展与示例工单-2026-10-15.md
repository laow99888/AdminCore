# 模块扩展与示例工单

本批交付一个完整、默认关闭的业务模块，以及可复用的代码内声明。示例有真实数据表、API 和页面，覆盖权限、数据范围、参数、菜单、审计、版本冲突、创建幂等和关闭后数据保留。后续代码生成器已另行完成当前范围，物理依赖包裁剪仍按清单继续实施。

## 二开操作手册

先在独立生成的项目开发并提交基线，初始化方法见[底座版本与项目升级](底座版本与项目升级.md)。以已有 `example` 为工作样本，以下顺序可以逐项运行和复核：

1. 阅读 `backend/apps/example/models.py` 的 WorkItem 和 `migrations/0001_initial.py`，确认作者、版本、索引和约束。新增模型保留用户外键与版本规则；执行 `python manage.py makemigrations` 后审核迁移，勿复制旧迁移编号冒充已执行。
2. 对照 `serializers.py`、`views.py`、`urls.py`，明确输入白名单、只读作者、创建幂等、更新/删除版本和事务内复核。新接口逐一调用已有数据范围、安全写和审计方法；仅在 manifest 声明权限不会自动保护自写 API。
3. 在 `manifest.py` 声明模块、路径、权限、菜单、参数和资源，显式登记 `apps/core/modules.py` 与 `INSTALLED_APPS`。模块关闭仍保留应用和迁移。运行 `python manage.py check`、`migrate`、`bootstrap_admincore`；旧角色不会自动获得新增权限。
4. 以 `frontend/src/views/example` 和 `frontend/src/api/index.ts 中的 exampleApi` 为例实现页面/API，登记 `frontend/src/modules/registry.ts` 并补翻译。沿用基础表格、表单、草稿离开保护与冲突提示，敏感字段不能靠隐藏按钮保护。
5. 针对新模块增加服务端越权/字段注入/事务回滚/幂等/版本测试，以及桌面/手机的加载、空、错误、禁用与撤权测试。现成样本位置可用 `rg --files backend/tests frontend/e2e` 找到 example/contract 相关文件；不机械改名后把原断言当新模块验收。
6. 从 backend 运行 `python -m pytest`、`python manage.py makemigrations --check --dry-run`、`python manage.py spectacular --validate --fail-on-warn --file schema.yml`；从 frontend 运行 `npm run lint`、`npm run test:typecheck`、`npm run test:coverage`、`npm run build`、`npm run check:bundle`、`npm run test:e2e`。
7. 在底座仓库运行 `python scripts/validate_example.py`，得到真实 PostgreSQL/Nginx 的当前示例验收。二开模块需要参照此脚本构造自己的隔离数据和启停测试，不能用原示例通过代替新模块通过。升级按底座升级文档先备份、演练，再做正向迁移与业务验收。

简单单表业务也可使用[代码生成器与真实接入](代码生成器与真实接入-2026-10-15.md)的显式计划/预览/选择流程，先审核生成差异。生成器覆盖常见 CRUD，复杂关系、外部副作用和业务状态机仍需建模和专门测试。每次二开应记录本清单要求的范围、默认启用、依赖、权限、关闭行为和可重复验收六项。

## 范围与启用

`example` 在 minimal、standard、demo 中均默认关闭。正式环境保持关闭，没有新增工单、参数覆盖值或示例菜单；权限只登记，不向已有角色自动授予。

显式启用时，把 `example` 加入已有 `ADMINCORE_MODULES` 列表，保留原模块。管理示例参数还需 `system`；不开启 system 时使用代码默认标题上限120字。参考独立精简项目配置：

```dotenv
ADMINCORE_PRESET=minimal
ADMINCORE_MODULES=example,system
```

该组合搭配 `compose.minimal.yml` 实测只需 db/backend/frontend，单 Gunicorn 进程、四个线程和本地缓存，无 Redis/worker/beat。多进程和标准预设继续使用共享 Redis 缓存。改变预设/模块需重新创建容器；profiles 不会自动停止已运行的旧服务。已有项目不得通过删除数据卷切换模块。

## 业务行为

页面 `/example`，API `/api/v1/example/items/`，权限分为 `example:read/create/update/delete`。字段为标题、说明、待处理/已完成、普通/高优先级。创建者只能由当前身份确定；拒绝提交创建者、额外字段和非法状态。

普通用户默认只能看到自己的工单；可通过组织管理为 `example` 配置已有五类数据范围。管理员沿用现有范围规则。关闭组织入口仍执行保存的数据范围。创建后也复核新记录是否可见；不允许创建到本人无法访问的范围。

新建提交版本0，保存为版本1。更新和删除必须提交读取到的版本，冲突409，不覆盖他人修改。创建接受显式 `Idempotency-Key`，同身份/接口/载荷重放同一结果，同键不同载荷409；失败回滚。重放仍复核身份、设备、权限及记录可见范围。幂等缓存沿用24小时保留，含当次业务响应；审计只保存状态、优先级、创建者、版本和标题摘要，不保存正文。

写入锁顺序为用户、设备、幂等记录、业务行。等待期间账号停用、设备撤销、权限或范围收紧，等待后的写入被拒绝。业务变更和审计共用事务，审计失败不保留业务写入。工单引用创建者，存在工单时删除用户返回409；批量删除整体回滚，避免删除作者后失去归属。

列表支持标题搜索、状态/优先级过滤、分页和白名单排序。前端复用现有组件、图标和主题，标题/正文按纯文本显示，采用本地表单草稿守卫和同步提交锁。冲突保留输入，重新加载必须确认，失败保留输入并支持重试。读取或操作权限撤销后清除旧数据与草稿，迟到响应不能恢复界面。

## 注册规范

后端 `apps/example/manifest.py` 使用 `core/contracts.py` 的 `Module`、`Parameter`、`MenuDeclaration`；声明仅含静态数据，不导入模型或查询数据库。应用显式加入 `INSTALLED_APPS`，manifest 显式加入 `core/modules.py`；不从目录或环境变量执行任意插件。

声明负责 API前缀、页面前缀、模块依赖、任务名、权限、菜单、参数、数据范围资源和审计白名单。启动拒绝重复项、核心入口覆盖、菜单越界、缺失/循环依赖、权限格式错误和无界参数。参数仅允许本模块命名空间内的有界业务值，不登记密码、密钥、安全配置或任意 Django 设置。

每个当前登记模块已补齐 `contract_version=1`、`default_enabled` 和 `conflicts` 元数据；支持单侧互斥，拒绝依赖闭包中的互斥能力。变更前运行 `python manage.py check_modules --modules <完整集合>` 只读查看启停影响，不自动修改配置或删除数据，见[模块元数据与只读预检](模块元数据与只读启停预检-2026-10-15.md)。

注册权限通过初始化命令登记；升级已有角色不自动扩权。菜单在模块第一次启用时补录一次，此后保留管理员修改和删除结果；关闭模块不会消耗首次初始化标记。新增参数自动进入白名单，模块关闭后隐藏，存量覆盖值保留。

前端只需在 `src/modules/registry.ts` 显式登记组件懒加载、模块名、路径、页面权限和标题。路由、进入校验、导航裁剪及旧后端兼容保护共用该声明。后端契约中的页面权限参与当前路由和权限刷新；服务端只提供元数据，不能指定可执行组件地址。API封装、页面和翻译仍由业务模块实现。

历史内置模块已有入口/种子保持兼容，尚未全部迁移到新的完整 manifest，也未实现自动安装任意第三方插件。新增资源须显式调用统一数据范围入口和审计方法，声明本身不代替授权实现。

## 契约、迁移和回退

对外 `contract_version` 保持1；本批 `page_permissions` 和 `scope_resources` 为可选新增字段。旧前端忽略新增字段，新前端接受旧字段集合；后端未登记示例时，新页面保持关闭。删除字段、改变字段含义或授权规则需要新契约版本，并在升级文档中明确迁移和兼容窗口，不能静默更改v1。

迁移顺序由 Django 依赖确定：`core.0008` 依赖core.0007，增加范围可选值；`example.0001` 依赖可交换用户模型的迁移，新增工单表、索引和约束。所有 app 和迁移在模块关闭时继续保留，启停不删除表、数据、参数、审计或安全策略。关闭期间迁移和重复初始化已通过独立实际数据库验收。

回退应用代码应保留新增表；不要反向迁移删除工单或范围记录。新版已登记的 `example` 范围旧代码不认识，回退前需评估所有已有范围和前端契约，不能宣称任意旧代码兼容。正式升级仍需数据库/媒体快照和停写检查。
