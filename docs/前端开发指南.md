# 前端开发指南

Vue、TypeScript、Element Plus 与运行时以 [版本要求](../版本要求.md) 和 [package.json](../frontend/package.json) 为准，安装使用 npm ci。先从 [能力地图](ai/能力地图.md) 找页面与 API，组件契约统一见 [基础组件使用手册](基础组件使用手册.md)。

## 页面与菜单

基础路由在 [router/index.ts](../frontend/src/router/index.ts)，内置可选页面在 [moduleRoutes.ts](../frontend/src/router/moduleRoutes.ts)，新增业务通过 [modules/registry.ts](../frontend/src/modules/registry.ts) 显式登记懒加载页面。

权限和菜单来自后端声明及当前账户，不在 AppSidebar 写静态菜单数组。模块、功能权限和路由守卫共同决定页面准入；后端独立授权。先看同类页面的路由/布局再添加容器，避免重复嵌套 AppLayout；保持标题、面包屑与返回行为一致。最小构建裁剪与运行时关闭分开处理。

## API 与状态

复用 [request.ts](../frontend/src/api/request.ts)、[publicRequest.ts](../frontend/src/api/publicRequest.ts) 和现有 API 文件；生成契约通过 [sdk.ts](../frontend/src/api/sdk.ts) 使用。接口变更执行 npm run sdk:generate，不手改 generated 文件。

认证状态在 [stores/auth.ts](../frontend/src/stores/auth.ts)，不是旧文档中的 user.ts。Token/Cookie 传输由认证层负责，页面不另存令牌或重写刷新。保持登录、退出、租户切换的世代和跨标签同步。

复用 [usePageState](../frontend/src/composables/usePageState.ts)、[useLatestRead](../frontend/src/composables/useLatestRead.ts)、[useEditConflict](../frontend/src/composables/useEditConflict.ts)、[useUnsavedChanges](../frontend/src/composables/useUnsavedChanges.ts)。旧响应不能覆盖新状态，409 保留草稿，由用户明确选择处理方式。

## 组件与视觉

BaseTable/BaseForm/BaseDialog 的 Props、事件、插槽及可编译示例只在 [组件手册](基础组件使用手册.md) 维护，不在本指南重复过时样例。列表配置、查询方案和跨页选择复用现有能力。

使用 [design-tokens.css](../frontend/src/styles/design-tokens.css) 的 CSS 变量与 [globals.css](../frontend/src/styles/globals.css) 的 Element Plus 适配。主题没有 theme-config.ts 入口。图标使用现有 Lucide 家族，图标按钮提供可访问名称。文案沿用 [i18n](../frontend/src/i18n/) 与 uiText 的现有方式。

检查明暗主题、窄屏、加载、空、错误重试、禁用和键盘行为。复杂页面按职责拆分，不能以行数代替正确性；富文本和私有文件预览用现有安全组件。

## 验证

运行 lint、test:typecheck、相关 Vitest、build、check:bundle；公共表格/表单/对话框还跑 test:coverage，页面行为跑对应 Playwright。命令与隔离边界见 [验证与交付](ai/验证与交付.md)。API fixture 测试和真实后端验收分别报告；共享组件变更检查受影响调用方。
