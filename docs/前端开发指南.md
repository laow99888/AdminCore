# AdminCore 前端开发指南

## 项目概览

AdminCore 前端是一个基于 **Vue 3 + TypeScript + Element Plus** 的现代化中后台管理系统框架。

### 技术栈版本

固定版本以 [版本基线](../版本要求.md) 和 `frontend/package.json` 为准；日常安装使用 `npm ci`，提交并保留 `package-lock.json`。

### 自动化检查

运行 `npm run lint`、`npm run test:typecheck`、`npm run test:coverage`、`npm run build`、`npm run check:bundle`。首次浏览器测试先执行 `npx playwright install chromium`，再执行 `npm run test:e2e`。Playwright 自动启停独立的 18411 预览服务器；API 使用隔离响应，不修改真实数据库。失败截图、trace 保留在 `test-results/`，CI 上传诊断产物。

BaseForm/BaseTable/BaseDialog 的覆盖率门槛为语句/函数/行 80%、分支 70%。覆盖率仅针对这三个组件，不代表整站覆盖率。新增基础组件行为应补充交互用例。路由保持懒加载，Element Plus 按模板组件自动引入；图表只注册使用的折线、饼图及组件，并保持独立懒加载块。主题直接使用 CSS 变量，已删除未使用的 `theme-config.ts`。

## 核心原则

### 1️⃣ 设计规范优先

**所有颜色、间距、圆角都必须使用 CSS 变量，不允许硬编码！**

```vue
<!-- ❌ 错误 -->
<div style="color: #14b8a6; padding: 16px; border-radius: 12px;"></div>

<!-- ✅ 正确 -->
<div class="component"></div>

<style scoped>
.component {
  color: var(--color-primary-500);
  padding: var(--spacing-lg);
  border-radius: var(--radius-lg);
}
</style>
```

### 2️⃣ 明暗主题支持

每个组件都必须支持明暗两种主题。使用 `.dark` 类选择器：

```css
/* Light 模式（默认） */
:root {
  --color-bg-page: #f9fafb;
  --color-text-primary: #111827;
}

/* Dark 模式 */
.dark {
  --color-bg-page: #020617;
  --color-text-primary: #f3f4f6;
}
```

### 3️⃣ 代码简洁清晰

- 组件单个文件不超过 300 行
- 函数名、变量名要自说明
- 使用 TypeScript 类型注解
- 遵循 Vue 3 Composition API 风格

### BaseForm（表单）

```vue
<template>
  <BaseForm
    v-model="formData"
    :fields="formFields"
    :loading="isSubmitting"
    submit-text="提交"
    @submit="handleSubmit"
  />
</template>

<script setup lang="ts">
import { ref, reactive } from 'vue'
import { BaseForm } from '@/components'

const formData = reactive({
  name: '',
  email: '',
  status: 'active',
  description: '',

const formFields = [
  {
    prop: 'name',
    label: '用户名',
    type: 'text',
    placeholder: '请输入用户名',
    required: true,
  },
  {
    prop: 'email',
    label: '邮箱',
    type: 'email',
    placeholder: '请输入邮箱',
    required: true,
  },
  {
    prop: 'status',
    label: '状态',
    type: 'select',
    options: [
      { label: '活跃', value: 'active' },
      { label: '禁用', value: 'disabled' },
    ],
  },
  {
    prop: 'description',
    label: '描述',
    type: 'textarea',
    rows: 4,
  },
]

const isSubmitting = ref(false)

const handleSubmit = async (data: any) => {
  isSubmitting.value = true
  try {
    // 调用 API
    console.log('提交数据', data)
  } finally {
    isSubmitting.value = false
  }
}
</script>
```

## 主题切换

主题切换已自动集成到 AppHeader 中。用户点击主题按钮会自动：
1. 切换 `<html>` 上的 `.dark` 类
2. 保存用户偏好到 localStorage
3. 更新所有使用 CSS 变量的组件

手动切换主题（如需要）：

```ts
import { useThemeStore } from '@/stores/theme'

const themeStore = useThemeStore()
themeStore.toggleTheme()  // 切换主题
```

## 常见问题

### Q: 如何修改主题色？

编辑 `src/styles/design-tokens.css`：

```css
:root {
  --color-primary-500: #your-color; /* 改这里 */
}
```

所有使用 `var(--color-primary-*)` 的地方都会自动更新。

### Q: 如何添加新的全局样式？

在 `src/styles/globals.css` 中添加。它会自动应用到所有页面。

### Q: 如何禁用某个菜单项？

编辑 `src/components/layout/AppSidebar.vue` 中的 `menuItems`：

```ts
menuItems.value = [
  { path: '/', label: '仪表盘', icon: '📊' },
  // { path: '/users', label: '用户管理', icon: '👥' }, // 注释掉隐藏
]
```

### Q: Element Plus 样式不对怎么办？

检查 `theme-config.ts` 中的主题配置，确保颜色值正确。

## 最佳实践

1. ✅ **使用 CSS 变量**：所有色值、间距都用变量
2. ✅ **支持明暗主题**：永远记得 `.dark` 前缀
3. ✅ **类型注解**：使用 TypeScript 提高代码质量
4. ✅ **组件复用**：优先使用已有组件，避免重复代码
5. ✅ **国际化**：新加的文案都放到 i18n
6. ✅ **响应式设计**：考虑移动设备适配
7. ✅ **性能**：按需导入，使用 `<script setup>`
