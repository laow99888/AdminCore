# 工程约束与扩展规则

本文定义新增业务必须维持的约束；具体函数参数从 [能力地图](能力地图.md) 指向的实现与测试读取。

## 认证与授权

1. 复用现有会话，不另写登录或 Token 存储。浏览器 Cookie 模式的刷新锁、世代和租户校验必须保留；前端走统一请求层。
2. 后端声明动作级权限并限制对象查询范围，详情/写入/导出/关联选择/搜索也执行相同范围。通过动作权限校验后，对象不存在或不在可见范围按现有 404 语义处理；动作权限本身被拒绝仍是 403，不能把所有拒绝都改为 404。
3. 多租户业务明确 tenant 外键与查询范围、唯一约束、关联对象租户匹配。后台任务使用可信来源的租户上下文并在结束时清理；不得相信客户端传来的 tenant 或 creator。
4. 业务字段登记可读/可写策略，列表、详情、导出、报表、审批快照和关联标签都要过滤；拒绝越权写字段，不能只在页面隐藏。示例工单是事务示例，不能视为所有字段策略的完整实现。
5. 显式公开入口同步维护授权契约及测试。角色名不代表管理员身份；已有角色不会因初始化自动获得新增业务权限。

## 事务、并发与副作用

- 在事务内重新锁定并复核当前操作者、原会话、权限、范围和业务行，再执行写入。参照目标模块的锁顺序；生成业务与审批联动尤其保持审批行在业务行之前，避免反向锁定。
- 修改/删除携带当前版本；冲突返回 409，前端保留草稿供用户决策，不能自动覆盖。创建的 version、幂等键及重放行为遵循同类实现。
- 业务状态、审计和必要 outbox 事件在同一事务提交。外部发送、文件转换等使用既有任务/outbox；重试前与执行时再次校验当前资格，不能把提交时的授权永久冻结。
- 所有批量入口明确整批或逐项事务语义，并覆盖重复 ID、部分越权、失败恢复与重试。不要把已有用户批量整批回滚语义套到逐行导入。
- 查询显式过滤/排序白名单、稳定分页和预算；金额用 Decimal，主子表聚合避免连接重复计数。SQLite 用例不能证明 PostgreSQL 行锁与并发正确。

## 文件与外部集成

- 文件通过私有文件接口；关联时复核权限、租户与引用，读取及历史版本也重新鉴权。业务附件使用引用保护，不能仅保存可猜测下载 URL。
- 上传、预览、导出遵守大小、格式、配额、扫描和超时限制；分片清理只处理会话专属暂存目录，不能删除已提交文件。
- 集成开关、凭据与业务启用分别配置。邮件、短信/Webhook、SSO、机器身份和异地备份保持按需启用；没有真实供应商验收就报告该范围未验证。
- 审计保存声明的必要值或摘要；密码、令牌、完整联系方式、任意请求体不写审计或日志。错误消息不回显秘密。

## 扩展、数据与升级

- 新业务有独立 app、manifest、前端页面和测试，显式登记到后端及前端注册表；新增通用能力才评估修改基座。业务规则放业务服务或生成模块扩展文件，生成前先审阅差异。
- Django 模型改变提交迁移，检查多租户关联与索引。数据库采用先扩展、回填、再移除的兼容流程；`managed=False` 不会自动建立数据库约束。
- 模块关闭保留应用、迁移和数据；组织维护关闭后持久化数据范围仍生效。精简构建与运行时关闭是两种操作，恢复要重建完整前后端。
- `admincore.project.json` 由升级工具维护；业务项目单独管理自己的产品版本。不得手改基线 SHA 来跳过升级验收。
- 依赖变更同步锁文件及相应构建，不能只改文档或使用不固定的最新版本。API 废弃按既有兼容窗口办理。

## 页面与交付

复用 BaseTable/BaseForm/BaseDialog、CSS 变量、Lucide 图标和现有国际化；检查加载、空、错误、禁用、冲突、窄屏与键盘行为。菜单来自声明/服务端与当前权限，隐藏侧栏不是关闭接口。修改共享组件同时验证受影响调用方。

新增业务按 [业务开发流程](业务开发流程.md) 交付；检查与资源收尾按 [验证与交付](验证与交付.md)。


## 本轮补充的共享契约

- 角色名、字典/岗位/消息模板/报表编码在当前租户中唯一；空租户作为独立全局范围仍唯一。幂等键按租户、操作者、scope 和 key 共同隔离；同范围同键异载荷或正在处理返回 409，不跨租户重放。
- `is_staff`/`is_superuser` 是平台级管理员，不能将普通租户管理员映射为 staff；租户角色使用 TenantMembership。对象隔离必须在 queryset 和写服务锁内执行，不能依赖前端或仅覆盖 has_object_permission。
- 新的只读列表权限快照限定当前 serializer 实例；禁止跨请求缓存授权或把快照用于写权限裁决。
- 简单通用表单可用 BaseForm，复杂条件业务表单用在线表单运行时或生成组件。BaseForm 日期输出 YYYY-MM-DD，时间输出含时区偏移的 ISO 字符串；加载另一条记录时同步更新 resetKey，普通输入保持原重置基线。列表时间统一用 formatDateTime，按浏览器本地时区展示。
- contracts/online-form-values.json 同时由前后端测试读取，区分字段缺失、显式清空、默认值、隐藏字段和明细；金额继续用十进制字符串。
- 设计器遇到 409 保留本地草稿，通过 useEditConflict 显式查看并应用服务端版本。模块缓存跟随用户和租户失效；刷新网络/5xx 故障保留凭证但不重放本次操作，认证和协议失败仍关闭会话。
