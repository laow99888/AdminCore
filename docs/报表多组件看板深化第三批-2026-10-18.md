# 报表与多组件看板深化

本批承接[功能深化路线图](功能深化评估与路线图-2026-10-18.md)第 4 项。完成单数据源报表的多指标与日期粒度，以及多个独立授权报表组成的看板：布局、统一筛选、显式联动、手动刷新、分页明细下钻。仍使用现有可选 `reports` 模块，不新增依赖或常驻服务。

## 配置与使用

报表构建器支持两个维度、最多四个指标和六个固定筛选。指标使用 `count(id)`、数值字段 `sum` / `avg`；编码以 `m_` 开头且不与模型字段重名，显示名称可以自定义。饼图只允许一个指标；折线、面积和柱图显示多个系列。表格保留后端返回精度，指标显示只用文本去除多余小数尾零，不经过浮点转换；图表绘制会将数值转换为 JavaScript Number，不能用图表的浮点显示代替金额核对。

日期字段支持日、周、月、季度、年分组，默认按日；周从周一开始。时区使用服务端当前 Django 时区，不支持由浏览器任意切换查询时区。PostgreSQL 与 SQLite 均验证上海时间跨年边界及分组后的下钻；通过日期输出字段完成一次时区转换，避免嵌套截断重复转换。

新建时选择“大屏”，可以添加最多八个组件。组件可以使用不同的已登记数据源，通过上移/下移控制顺序，选择半宽或整宽；手机自动单列，列表和运行结果优先显示，配置区排在后面。不提供自由画布拖放和任意像素定位。

统一筛选最多四个，每项显式绑定一个或多个组件的筛选字段，绑定字段的类型必须相同。名称、操作符、默认值和绑定均可以在界面编辑。`in` 使用最多 50 项的 JSON 数组，布尔值使用真实布尔值，金额保持十进制文本。点击“应用筛选并刷新”才生效；“恢复默认筛选”同时清除联动。

联动最多八条，只允许已配置的非日期维度绑定到类型相同的筛选字段。点击图表的数据点使用该组件第一项联动维度；表格提供每种联动维度对应的按钮，作为键盘和触屏操作入口。相同来源字段可以影响多个组件。一次操作只有一个当前选择，不递归传播联动，不隐式解释日期区间；空维度值不触发联动。

统一筛选、联动条件都以 AND 叠加在各组件固定筛选之上，不能替换固定条件。组合后每组件最多 18 项，结果最多 100 组；额外读取一组检查截断，并在页面明确提示不完整。最多八条聚合查询，各自使用现有 SQL 查询预算。组件依次执行，不承诺各图处在同一数据库快照；需要最新值时手动刷新，无后台轮询。

发布后定义不可直接编辑，可以“复制为新草稿”，指定新编码后保存发布。运行时筛选不回写定义。包含多个组件、统一筛选或联动的看板不能直接切换成单报表，避免无提示丢配置；应新建报表或显式移除多余配置。

## 权限与明细

定义管理继续使用 `report:read/create/update/publish` 权限及原管理员写入规则；前端同步禁用无权限的编辑、创建、复制和发布入口，运行权限不会授予定义写入能力。运行和明细接口都需要 `report:execute`。生成业务源额外要求当前业务读取权限。字段策略、数据范围、租户，以及文件源 ACL 继续复用公共机制。

运行前先校验并授权所有组件及新增筛选字段，再开始聚合；任一组件权限不足时整份看板失败，不返回部分结果。每次运行、下钻和分页重新鉴权，不使用保存时的权限快照，也不缓存聚合结果。

“查看明细”按图表已经应用的条件和选中行的完整维度重新查询；尚未应用的输入不会改变当前图表的明细条件。日期分组使用相同截断表达式回查，不将整个月误当作一天。只输出当前可读的 ID、已配置维度和指标原始字段，不允许客户端自选模型字段，不自动暴露关系、附件或私有摘要。明细每页最多 100 条，页码最多 100，使用 `has_more` 而非额外全量计数。

运行与明细响应使用 `Cache-Control: private, no-store`。前端开始刷新时清空旧结果，下钻失败也清空旧图表，切换账号、权限、租户、模块配置或卸载时中断请求并丢弃迟到响应。

## 兼容与接口

数据库模型没有变化，不新增迁移。旧 `metric` 定义、`value` 结果列和 GET `run/` 仍可使用，包括历史上采用单图定义的大屏。编辑旧定义时转换为 `metrics` 并保留原聚合语义。存量已发布定义保持原样；新大屏使用 `schema_version: 2`、`widgets`、`filters`、`links`，定义与运行选项均按白名单校验。

- GET `/api/v1/reports/definitions/{id}/run/`：按已发布默认条件运行。
- POST 同一路径：接受 `{filters: {筛选编码: 值}, selection?: {widget, field, value}}`。普通单报表只接受空选项。
- POST `/api/v1/reports/definitions/{id}/details/`：接受 `{widget?, options?, group, page?, page_size?}`；普通报表的 widget 为 `single`，看板必须指定实际组件编码。

模块数据源目录增加经过字段权限过滤的 `field_types`，用于编辑和运行时控件。更新了 OpenAPI 与前端 SDK；完整配置共 201 条路径。

## 保留范围

本批没有实现同比/环比、跨表连接、主子表明细聚合、报表结果导出、自由拖放画布、定时刷新或自动推送。日期粒度不等于时间对比，多组件组合也不等于任意数据建模。这些仍在路线图中，不能记为全部报表深化已完成。
