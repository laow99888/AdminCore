# 外部通知、资源导入、开放凭证与隔离演示验收

本批交付四渠道消息、用户/角色/岗位登记导入、独立只读开放凭证、独立演示项目及基础组件手册。对应实现提交 `39306e8`、修正 `736647b`、文档及浏览器用例 `61e0967`。后续 SSO、Office 转换和编辑冲突收口属于下一批，未混入此次发布产物。

## 功能范围

- [外部通知渠道](外部通知渠道与验收-2026-10-16.md)：inapp/SMTP/Webhook/Twilio 短信共用模板及可靠事件；新增出站目标固定、公网解析校验、TLS、HMAC轮换和接收端防重放辅助。短信有独立 PostgreSQL 持久屏障，不确定结果终止，需人工核对供应商记录；201仅代表接收。
- [资源导入](资源导入与默认停用-2026-10-16.md)：用户、角色、岗位只新增；角色和岗位默认停用，不导入授权或任职。每行独立保存点、审计及账本，执行期间逐行复核身份和权限；日志/文件元数据保留只导出。取消浏览器请求不能撤销服务器已经登记的任务，执行结果在任务中心查看。
- [开放凭证](独立开放凭证与只读API-2026-10-16.md)：独立 ApiToken、一次显示、本人管理、到期/撤销/改密失效、SQL限流及预算；固定开放任务和工单摘要。模块默认关闭，不为已有角色自动增加权限。
- [独立演示](独立演示项目与安全重置-2026-10-16.md)：从指定 Git 提交导出无源凭据的新项目，独立数据库、卷、随机三账户凭据、本机端口；签名实例确认后停写重置，旧会话失效，生产拒绝演示。重置保留媒体卷，不自动清除后来上传的孤儿文件。
- [组件手册](基础组件使用手册.md)：真实 API 与可编译示例；无生产路由、无 Storybook 新依赖。CI 验证文档示例类型。
