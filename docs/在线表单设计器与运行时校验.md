# 在线表单设计器与运行时校验

P2-06 提供一个默认关闭的 `online_forms` 可选模块。启用后，管理员可在 `/online-forms` 创建和编辑草稿表单，发布后通过 `/online-forms/{code}` 运行表单并保存记录。

## 范围

- 字段类型：单行文本、多行文本、数字、下拉选项、日期、布尔值。
- 表单定义限制字段数量、键名、标签长度、选项数量和数值范围。
- 发布会固定当前定义版本；已发布版本不可直接修改，只能归档。
- 运行时服务端重新校验必填、默认值、类型、长度、范围和选项，未知字段直接拒绝。
- 记录按创建者隔离；读取和更新需要记录权限，更新要求提交当前版本号。
- 创建支持 `Idempotency-Key`，同一请求重放返回原结果，不同请求摘要返回冲突。

## 安全边界

定义中拒绝脚本、模板、组件、URL、SQL 等危险字段和深层/超限结构；服务端不执行定义中的代码、HTML 或查询语句。表单模块默认不启用，需在 `ADMINCORE_MODULES` 中显式加入 `online_forms`，停用后保留数据但撤下模块路由。

## 验收

专项测试覆盖发布不可变、恶意定义拒绝、运行时校验、幂等重放和跨用户记录隔离；严格 OpenAPI、SDK 漂移检查、前端类型检查、lint、构建及 Django 迁移检查均通过。真实部署中的浏览器登录和容量验收仍按项目环境执行。
