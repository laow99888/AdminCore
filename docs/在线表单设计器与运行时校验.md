# 在线表单设计器与运行时校验

## 当前阅读入口

本页下文保留 P2 首版范围及当时验收。当前定义已支持 V2 的分组、条件、主子明细及更丰富字段，后续还增加同编码发布历史、受控计算、附件、业务关联和审批；按 [V2 定义](在线表单设计器2.0第二阶段-2026-10-18.md)、[发布生命周期](在线表单生命周期深化-2026-10-18.md) 及 [能力地图](ai/能力地图.md) 的表单两行定位。定义和记录的 `form_version` / `version` 含义不同，新客户端提交应携带加载时的 `form_id`。

## P2 首版范围与验收（历史）

P2-06 提供一个默认关闭的 `online_forms` 可选模块。启用后，管理员可在 `/online-forms` 创建和编辑草稿表单，发布后通过 `/online-forms/{code}` 运行表单并保存记录。

## 范围

- 字段类型：单行文本、多行文本、数字、下拉选项、日期、布尔值。
- 表单定义限制字段数量、键名、标签长度、选项数量和数值范围。
- 发布会固定当前定义版本；已发布版本不可直接修改，只能归档。
- 运行时服务端重新校验必填、默认值、类型、长度、范围和选项，未知字段直接拒绝。
- 记录按创建者隔离；读取和更新需要记录权限，更新要求提交当前版本号。
- 创建支持 `Idempotency-Key`，同一请求重放返回原结果，不同请求摘要返回冲突。

## 安全边界

定义中拒绝脚本、模板、组件、URL、SQL 等危险字段和深层/超限结构；服务端不执行定义中的代码、HTML 或查询语句。表单模块默认不启用，需在 `ADMINCORE_MODULES` 中显式加入 `online_forms`，停用后保留数据但撤下模块路由。

## 验收

专项测试覆盖发布不可变、恶意定义拒绝、运行时校验、幂等重放和跨用户记录隔离；严格 OpenAPI、SDK 漂移检查、前端类型检查、lint、构建及 Django 迁移检查均通过。

隔离 PostgreSQL/Redis/Nginx 与真实 Chromium 桌面/手机验收通过：实际登录、创建/发布表单，发布后禁用字段和保存按钮，运行页标签关联输入框，必填空值由服务端拒绝，合法填写保存且清空输入，SQL 复核两条实际记录内容。入口为 `python scripts/validate_p2_pages.py`，不连接已有站点。实际供应商部署、所有字段类型的浏览器矩阵及容量仍按项目环境执行。
